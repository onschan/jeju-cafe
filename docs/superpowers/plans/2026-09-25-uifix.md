# 화면 깨짐 전면 수리 (375×812) — uifix

사용자 피드백: "**패치가 제대로 안 된 것 같은데 UI도 깨지고.**"

브랜치 `uifix`. 수치는 전부 375×812 실기기 폭에서 `getBoundingClientRect()`로 잰 값이다.
브라우저 도구가 스크린샷을 파일로 못 남겨서(뷰어 샌드박스가 다운로드를 막는다) **좌표·크기 수치**로 전/후를 적는다.

## 0. 기준선 (수정 전, 새 게임 `?game`)

| 잰 것 | 값 |
|---|---|
| 상단 총 높이 | **96px** (상단 바 28 + 목표 줄 24 + 도전 줄 20 + 오늘 할 일 24) |
| 상단 1줄 칸 사이 간격 | **2px** (★ 오른쪽 끝 252 · 응모권 칸 시작 254) |
| 대화창 높이 | **244px 이상**(`minHeight: 30vh`), 창 바닥이 화면 바닥에서 8px |
| 대화창이 가린 하단 바 | **48px 전부** |
| 가로 스크롤 | 없음 (`scrollWidth` 375) |

### 안 고친 것 (이유와 함께)

| 것 | 왜 그대로 뒀나 |
|---|---|
| 오늘 할 일 줄 글자가 말줄임(`…`)으로 끊기는 경우 | solver 라벨이 22자를 넘을 때가 있다(「명소 「동문시장」 투자 (₩100만)」). 줄 폭은 238px·약 17자. 잘림이 아니라 **말줄임 + 탭하면 그 수로 카메라가 가는** 설계라 그대로 뒀다. 라벨 쪽을 줄이는 건 solver 트랙 일 |
| 상단 2줄의 버튼이 26~28px (44px 미만) | 사용자 지시가 「상단 총 높이 ≤ 56px」이라 둘을 같이 지킬 수 없다. 상시 표시 줄은 정보이고, 누르면 여는 창은 전부 44px 이상이다. 하단 바 버튼은 44px 유지 |
| 메시지 줄 24px | 같은 이유(상시 표시 줄). 누르면 열리는 「최근 메시지」 목록은 44px |
| 「경영 현황」(상단 바 탭)과 「장부 › 경영」이 같은 화면 | 같은 정보가 **한 화면에 두 번** 나오는 게 아니라 **가는 길이 둘**이다. 상단 바 탭은 지름길이라 남겼다 |
| 「앞으로」 목록에 4년차인데 「2년차 맞이하기」가 남아 있음 | UI가 아니라 목표 데이터(`goals.ts`) 쪽 순서 문제 — UI 트랙에서 손대면 수치가 움직인다 |
| 부탁 배지 27, 응모권 248 | 밸런스 수치(쌓이기만 함). UI 트랙에서는 안 건드린다 |
