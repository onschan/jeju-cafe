## 3. 사용자 피드백 P0 — 손님 경로

> "주차장을 사거나 땅을 넓혀도 손님이 정류장에서만 온다"

- **비중 고정**(`entry.ts routeShare`): 주차장이 이어져 있으면 하루 손님의 **30%**(4칸)~**45%**(8칸+), 올레길 **20%**, 정류장은 나머지 — 총량 불변(밴드 유지). 렌터카 시간대 10~17시 → **9~20시**.
- **길 연결 판정 분리**: `routeConnected`(진입점→시설)에 더해 **`routeLinked`(시설 앞 칸 → 자리)**. 안 이어졌으면 카드에 빨간 「길이 끊겼어요」 + **「자동 잇기」 버튼**(`autoLinkRoute`, `rooms.ts autoConnectFrom` 재사용).
- **도착 연출**(`FxEvent arrive`): 주차장 손님은 2~4명이 **한 차**로 모여 내리고(남은 한 명은 20시), 렌터카·셔틀·배 스프라이트가 가장자리에서 들어와 1.2초 → 2초 정차 → 나감 + 「렌터카 손님 3명!」 문구. 올레꾼은 문구만(걸어온다).
- **땅을 사면 경로 자동 개통**(`installRouteForParcel`): 서쪽 밭담 골짜기 → 올레 표식(3,11), 남쪽 용천수 샘터 → 셔틀 정류장(15,20), 북쪽 곶자왈 → 선착장(14,0)을 **무료로** 세우고 진입점까지 올렛길을 깐다 + 장면 창 「이제 올레꾼이 서쪽에서 걸어온다」. 선착장 ★3 조건 삭제.
- **주차장 해금 조건(쉼 시설 6개) 삭제** — 처음부터 ₩120만. 카드에 「오늘 여기서 온 손님 n명 · 상한 n」·「하루 손님의 30%가 여기서 와요」.
- 팁: `build:parking_lot` → "렌터카 손님이 동쪽에서 온다".

## 4. 사용자 피드백 — 짓기 단순화 + 업그레이드 트리

> "종류가 너무 많고 선택지만 많아 어지럽다. 부루마블처럼 테라스 업그레이드가 되게" / "중요도에 따라 배치하고 경관이 뭘 위해 있는지 보이게"

### 짓기 창 6타일 (중요도 순)

| 타일 | 한 줄 | 병목 배지 |
|---|---|---|
| 🪑 자리 | 손님이 앉아야 돈이 된다 | 자리 이용률 ≥ 90% → 「자리가 모자라요」 |
| 🍳 서비스 | 서빙이 빨라지고 만족이 오른다 | 직원 0 → 「서빙이 느려요」 |
| 🌷 매력 | 경관이 오르면 관광객이 온다 | 경관 < 4 → 「관광객이 안 와요」 |
| 🚗 유입 | 손님이 들어오는 문 | 경로 1종 → 「정류장에서만 와요」 |
| 🏠 실내·건물 | 비 오는 날도 자리가 있다 | (등급 3부터 보임) |
| 📋 전체 목록 | 150여 종을 탭별로 | — |

창을 다시 열면 늘 6타일 첫 화면(전체 목록만 기억). 하위 목록의 **트리 2단계부터는 짓기 잠금** — 「업그레이드 ▲」로만 얻는다.

### 업그레이드 트리 (`data/upgrade_tree.json`, `sim/tree.ts`)

같은 자리에서 종류가 바뀐다(id·이름 유지, **차액만**, 공사 기간은 새 단계). 조건은 등급·★·코너.

| 트리 | 1단계 | 2단계 | 3단계 | 4단계 |
|---|---|---|---|---|
| 자리 | 야외 테이블 ₩5만 (좌석2·경관0) | 파라솔 테이블 ₩7만 (좌석2·경관1) | 테라스 좌석 ₩60만 (좌석2·경관1) · 등급2 | 오름 뷰 벤치 ₩250만 (좌석4·경관3·2×1) · 등급3 |
| 놀거리 | 나무 벤치 ₩26만 (경관2) | 해먹 ₩90만 (좌석2) | 가마솥 족욕 ₩250만 (인기19·경관11·₩5천) · 등급2 | 노천 족욕탕 ₩1,400만 (인기30·경관20·₩8천·2×2) · 등급3·코너1 |
| 매대 | 오메기떡 매대 ₩90만 (인기12·₩3천) | 감귤 타르트 베이커리 ₩450만 (인기20·₩6.5천) · 등급2 | 브런치 식당 ₩1,100만 (인기36·₩1.2만) · 등급3·★2 | 오름 뷰 다이닝 ₩1,400만 (인기48·₩2.5만) · 등급4 |
| 정원 | 꽃밭 ₩3만 (경관2) | 동백 ₩50만 (경관3) | 야자수 ₩70만 (경관5) · 등급2 | 연못 ₩250만 (경관12·2×1) · 등급3·코너1 |
| 조명 | 정원등 ₩5만 (경관1) | 가로등 ₩8만 (경관1·밤 반경2) | 알전구 줄 ₩40만 (경관3·2×1) · 등급2 | 도대불 ₩350만 (경관3) · 등급3·★2 |

- **거리 보너스**(부루마블 독점): 같은 트리의 **2단계 이상** 시설이 한 줄로 3개 이어지면 그 줄 전부 **요금 +10%**(좌석 주문·시설 이용료). 기본 단계 줄은 안 센다(1년차 밴드).
- **전략 수치**: 카드에 「이 자리에서 올리면 +₩n/일」(solver `evaluate` 14일 롤아웃의 자금 차이 ÷ 14)·거리 줄. 배치 고스트엔 **얻는 것/잃는 것 두 줄**(`tradeoff.ts`): "+좌석 2 · +경관 1(자리 2곳) · 관광객 +3%/일" / "−유지비 ₩750/월 · 비 오는 날 빈다".
- 기존 150여 종은 삭제하지 않고 「전체 목록」 탭과 코너 조각·랜드마크로 남는다. 증축 Lv1~3(`upgrade.ts`)은 **트리에 없는 시설에만** 보인다. 목표 `facilityLv`/`upgraded`는 트리 단계(index+1)도 Lv로 센다.

### 경관의 목적 (`sim/appeal.ts`)

- **경관 → 관광객**: 자리 평균 경치가 관광객 태그 손님의 스폰 배수(**×0.85 ~ ×1.25**, 경치 3.75에서 1.0). 동네 손님은 1.
- **사진 → 평판**: 손님이 사진을 찍으면 그날 밤 평판 **+0.02/장**(하루 +0.15) → 이름 있는 손님·단골로.
- **「카페 매력도」 패널**(경영 현황 첫 화면): 인기(시설 인기 합)·경관(자리 평균)·서비스(만족률) 3개만 크게 + 탭하면 「올리는 법 2줄」, 병목 한 줄. 잔지표(날짜·자금 외 8줄·동네↔관광객 축)는 **「자세히」 접힘**.
- 경관 시설 카드·고스트에 「관광객 +n%/일」 즉시 수치(`sceneryGainText`).

### 점진 공개

등급 1~2에선 **실내·건물 타일·카페›본관/실내 탭·사람›라이벌·장부›명소/지역·연수·경로 계약이 아예 안 보인다**(잠금 표시 없음). 등급 3(소문난 카페)이 되면 나타나고 첫 등장 팁 「소문난 카페. 명소·대결·실내가 열렸다」.

## 7. 미해결 · 주의

1. **10년차 목표 105 미달** (봇 70~89) — 기존 회귀 방지선만. 5년차 목표 ≥95는 코너 사다리(g59 코너 5개)가 3년차에 풀리며 개선됐지만 seed에 따라 89~95.
2. **자동화 실플레이**: 튜토리얼 ①~⑤는 UI로 통과, ③ 인사는 손님 카드가 자동화 클릭으로 열리지 않아 `dispatch(greetGuest)`로 진행한 컷이 있다(버튼 자체는 `data-tut="greet"`로 존재·수동 확인). ⑤ 조각 2·3은 UI 클릭이 막히면 `dispatch(place)`로 넘어간다.
3. **거리 보너스 시각화 없음** — 카드 문구만. 맵 위에 띠를 그리는 건 후속.
4. **트리 밖 시설의 증축(Lv1~3)과 트리 업그레이드가 공존** — 「전체 목록」에서 지은 시설은 예전대로 증축, 트리 시설은 업그레이드. 장기적으로 하나로 합치는 게 좋다.
5. **`state.popularity`는 동네↔관광객 축**(−100~100)이고 매력도 패널의 「인기」는 시설 인기 합이다 — 이름이 겹친다.
6. 경로 `weight`(entryPoints)는 표지 굵기용으로만 남아 있다(실제 비중은 `routeShare`).
