## 1. 다리 — `src/ui/rushBridge.ts`

rush1의 인터페이스를 그대로 가정하고, 없으면 **UI 전용 임시 엔진**으로 같은 모양을 만든다.
sim이 들어오면 `hasSimRush(s)`가 true가 되어 임시 엔진은 저절로 잠든다. 지우는 곳은 `// TODO(rush1)` 표시.

```ts
interface RushState { phase:'idle'|'ready'|'run'|'done'; queue:RushGuest[]; score:number; combo:number; served:number; left:number; grade:RushGrade; endTick:number }
rushOf(s) · rushTimeLeftMs(s) · rushGradeNow(s)
seatFromQueue(guestId, objectId) · useStaffSkill(staffId) · rushPriority(objectId)
```

- 주간 리듬: `weekdayOf(clock)` = ((day−1)%7)+1. **5일 = 예고**, **6일 12시 = 러시**.
- 점수식(§2): 받은 손님×10 + 팁 + 자리 보너스 + 콤보(3연속부터 ×1.5) − 떠난 손님×15.
- 등급 S/A/B/C는 기준 점수(줄 길이×10) 대비 비율.
- 「러시 자동 진행」(설정): 켜면 자동 해결·점수 계수 `AUTO_SCORE_MULT`.
- 마지막 성적은 `localStorage`에 남긴다 — 진단·오늘 할 일이 읽는다 (sim이 생기면 sim 상태로 옮긴다).

## 2. 화면 — `src/ui/RushHud.tsx`

같은 맵 위. 새 씬이 아니다. 맵이 **70% 이상** 보이게: 상단 띠 36px + 왼쪽 줄 62px + 하단 카드 92px.

- **상단**: 남은 시간 바 · 점수 · 콤보(3 이상이면 불꽃). 일시정지 버튼(44px).
- **왼쪽 세로 줄**: 손님 얼굴 최대 6명 + 「+n」. 각자 인내 게이지(초록→노랑→빨강). 맨 앞은 테두리 강조.
- **하단**: 직원 스킬 카드 3~6장 — 초상·스킬 이름·쿨다운 원형 게이지. 탭하면 발동. 한 손 영역(하단 60%).

## 3. 조작

1. 줄 맨 앞 손님 탭 → 앉힐 수 있는 자리 **초록**, 못 앉히는 자리 **회색**(탭하면 이유 한 줄) → 자리 탭이면 배정.
2. 자리 먼저 탭해도 맨 앞 손님이 앉는다.
3. 주문이 밀려 **빨개진 자리** 탭 → 긴급 처리(가장 가까운 직원이 달려가는 연출).
4. 모든 성공 조작에 짧은 fx: 칸 위 `+n` 숫자(GameView.popText) · 콤보 불꽃 · 소리.

맵 칸 색은 `GameView.setRushMarks(marks)` 한 메서드로 (초록·회색·빨강).

## 4. 예고·정산 — `src/ui/RushShow.tsx`

금요일 알림 「내일 점심, 손님이 몰린다」 + 준비 체크리스트(빈 자리 n·직원 n·재료)
→ 토요일 카운트다운 3·2·1 → 러시 → **결과 카드**(등급 도장·받은 손님·놓친 손님·팁·콤보 최고·보상 + 「이래서 놓쳤어요」 한 줄) → 보상 상자(RewardPopup의 상자 연출 재사용).

## 5. 튜토리얼

인사(greet) 단계 삭제. 1막에 「첫 러시」(줄에서 2명 앉히기), 2막에 「직원 스킬 써 보기」.
판정은 sim 상태만 본다 — UI가 `tutorialNote('rushSeat1'|'rushSeat2'|'rushSkill')`을 남기고 sim은 그것만 읽는다(러시 상태에 기대지 않는다).
`tutorial.json`은 할망 말투로 다시 쓰고(한 줄 ≤22자) 인사·추천 문구를 뺀다. MiniCard의 인사·추천 버튼도 뺀다.
