## 3. 통합 뒤 고친 것

### 3.1 목표 사다리 정합
- `goals.json` 60개를 훑어 **랭크 숫자를 쓰는 목표 2개**를 정리했다.
  - g13 「카페 랭크 6 달성」 → 「이 동네에 이름나기」
  - g18 「카페 랭크 2 달성」 → 「소문 퍼뜨리기」 (없어진 팝업 원정을 말하던 대사도 갈았다)
- 진행 막대도 고쳤다: `goals.ts`의 `cafeRank`가 랭크(1~10)가 아니라 **「알려진 정도」 점수**(누적 손님·시설·손님층)를 보여 준다. 달성 판정은 그대로 랭크다.
- **조건 자체를 등급·★로 바꾸는 것은 되돌렸다.** 한 번 바꿔 재 보니(등급 2·평판 45 등) 사다리 앞쪽 문턱이 달라져 3년차 밴드가 깨졌다 — seed 2·3이 자금 1,050만·목표 28~30(밴드 2,000~5,000만·목표 ≥40). 보이는 숫자만 바꾸면 밴드가 안 흔들린다.
- `validate:goals --strict` 통과 (목표 60 · 문제 0).

### 3.2 `SAVE_VERSION` 21 → 22
- 다섯 트랙이 붙인 필드는 전부 optional이라 v21은 `backfill()`만으로 이어진다. `BACKFILL_FROM = [20, 21]`.
- 빠져 있던 backfill 2개를 채웠다: `monthCosts.contest`(+ 지난달 카드), 빚이 남은 옛 세이브의 `loan.dueMonthIndex`.
- 회귀 테스트 `save.test.ts`: v21 세이브에서 새 필드를 지우고 열어 전부 기본값이 차는지, 두 번 왕복해도 같은지.
- 타이틀 「옛 세이브는 백업됐어요」도 고쳤다 — backfill로 이어지는 v20·v21에는 「새 게임으로」라고 겁주지 않는다.

### 3.3 시설 밀도 가드
- 통합 뒤 landmark 제외 종류가 **정확히 60**(대회 트로피 포함)이라 가드가 꽉 찼다.
- **시설을 지우지 않고 가드의 뜻을 맞췄다.** 가드의 목적은 「짓기 창에서 넘겨 보는 카드 수」이므로,
  맵에 처음부터 있는 것(정류장·본관·용천수, `BuildWindow`의 `HIDDEN_IDS`)과 **보상으로만 얻는 트로피**(cost 0, 대회 우승)는 빼고 센다 → 지금 **56 / 60**.
  총량은 따로 **62**로 묶어 두어 보상·고정물도 무한정 늘지 않게 했다.
- 덜 쓰는 데코 2개를 지우는 쪽은 택하지 않았다. `corners.json`·`goals.json`·`parcel_scenery.json`과 스프라이트 시트 재생성까지 번져 통합 막바지에 위험이 크고, 가드가 재려던 밀도는 「사는 시설 종류 수」라 트로피를 세는 것이 오히려 틀렸다.

### 3.4 버그 3건
- **`isDoorReachable` false negative** (`path.ts`). 정류장에서만 BFS를 돌려서 주차장·올레로만 이어진 카페를 「손님이 못 온다」고 잘못 말했다. 열린 진입 칸을 다 보는 `entryPoints()`로 바꿨다(정류장이 맨 앞이라 거의 모든 경우 캐시된 BFS 하나로 끝난다). 진입 칸 좌표는 순환 import를 피해 잎 모듈 `layout.ts`의 `ENTRY_CELLS`로 옮기고 `entry.ts`가 그것을 쓴다. 회귀 테스트 `path.test.ts` 2건.
- **`entry.ts` `case 'olle'` 중복** — 닿지 않는 두 번째 줄 제거(땅 검사는 위 `parcelId`가 한다).
- **`BoardPanel.tsx` 금지 문자 화살표** 3곳 제거. JSX 텍스트라 기존 문자열 리터럴 검사를 빠져나갔다 → `noCliche.test.ts`에 원본 스캔 한 줄 추가.

### 3.5 대회 상금 재측정
contest 트랙이 단독으로 잰 ×4/×2.5/×1.5를 stakes 수입·비용까지 들어간 통합 상태에서 다시 재니 봇 5년차 자금이 **2억 275만**으로 상한 2억을 넘었다 → **×3.4/×2.1/×1.3**(5년차 1억 6,049만). 배율이 소수라 상금은 원 단위로 반올림한다(`prizeOf`).
