# 명당 튜토리얼 반복 — cfix

사용자 피드백: "**명당 튜토리얼에서 (시설이) 지어지는 시간 동안 튜토리얼이 성공이 안 되고 반복한다 — 완성이 기준이라.**"

브랜치 `cfix`. 375×812 새 게임을 손으로 2막 5단계(첫 명당 「꽃길」)까지 몰고 가서 화면을 확인했고,
판정·문구는 문자열 생성 함수 단위로 재현·검증했다(`src/ui/__tests__/cornerRepeat.test.ts`).

## 0. 재현 경로

1. 새 게임 → 프롤로그 건너뛰기
2. 1막: 야외 테이블 1개 → 메뉴판에 아메리카노 → 손님 카드 열기
3. 좌석 2개 + 첫 결제가 되면 **2막 「자리와 명당」**이 열린다
4. 4단계 「입지 보기」 켜기 → 하루 뒤 **5단계 「첫 명당 「꽃길」」** 대사
   ("꽃밭 옆에 벤치, 그 옆에 가로등. 셋이 모이면 「꽃길」 명당이다.")
5. 꽃밭(0일) · 벤치(**1일 공사**) · 가로등(0일)을 반경 2 안에 놓는다

이 시점의 상태: `완성 명당 0` · `짓는 중 1` · `cornersDoneIncludingWork 1`.

브라우저에서 실제로 본 것 (수정 뒤, 1년 3월 7일):

| 화면 | 전 | 후 |
|---|---|---|
| 맵 | 조각을 다 놓아도 「여기 놓으면 명당이 된다」 글로우가 남는다 | 마지막 조각을 놓는 순간 글로우가 사라지고, 닻 칸에 **반투명 「꽃길」 팻말 + 「1일」**이 선다 |
| 튜토리얼 | — | 다음 날 5단계가 아니라 **6단계 「명당 곁에 자리를」** 대사가 뜬다 (반복 없음) |
| 짓기 › 명당 탭 | 「명당 0/24」 | 「명당 0/24 · **짓는 중 1**」 · 꽃길 줄 「조각은 다 모였다 — 내일이면 완성」 |
| 할 일 창 등급 줄 | 「명당 0/1 — 여기가 제일 모자라요」 | 「명당 0/1 — 여기가 제일 모자라요 · **짓는 중 1**」 |

할 일 창 등급 줄만은 브라우저에서 수정 전 문구를 다시 보았는데, 그때 dev 서버가 **고친 모듈을 안 물고 있었다**(서버를 껐다 켜니 사라졌다).
공사 중 상태가 하루뿐이라 서버를 새로 띄운 뒤엔 이미 완공돼 있어, 이 줄은 단위 검증(`gradeProgress(...).building === 1` · `gradeRow.how`)으로 확인했다.

## 1. 진짜 원인 — sim은 맞았고, 되풀이하는 건 **안내**였다

`cornerMade`(5단계 done)는 이미 `cornersDoneIncludingWork`를 본다(botfix `23e1133`).
마지막 조각을 놓는 액션에서 `apply → checkGoals → checkTutorial`이 돌아 **그 자리에서 5단계가 끝난다.**
그래서 5단계 자체는 반복하지 않는다. 사용자가 본 「반복」은 **단계가 끝난 뒤에도 화면 여기저기가 계속 「명당을 하나 만들어라」라고 말한 것**이다.

| # | 어디 | 왜 되풀이했나 | 고친 것 |
|---|---|---|---|
| 1 | 5단계 글로우·짓기 타깃 (`tutorial.cornerMissingType`·`cornerCells`) | 조각을 **시설 id**(꽃밭·나무 벤치·정원등)로만 셌다. ① 조각이 다 모여도 마지막 종류를 돌려줘 「여기 놓으면 명당이 된다」 칸이 남았고, ② 대사는 「**가로등**」인데 타깃은 「**정원등**」이라 대사대로 가로등을 놓으면 같은 조각을 또 놓으라고 했다 | 조각을 **종류**(`pieceMatches`)로 본다. 다 모였으면 `cornerMissingKind` = `null`, `cornerCells` = `[]` — 글로우가 그 자리에서 사라진다 |
| 2 | 「할 일」 창 등급 줄 | 「명당 0/1 — 여기가 제일 모자라요」 (승급은 완공 기준인데 짓는 중이라는 말이 없었다) | 승급은 완공 기준 그대로, `GradeProgressRow.building`을 붙여 문구에 「짓는 중 1」 |
| 3 | 「할 일」 창 목표·이달의 과제 줄 | `buildingNote`가 **상단 한 줄(TodoLine)에만** 붙고 창 안에는 안 붙었다 | `todo.ts` 세 줄(목표·이달·승급)에 「짓는 중 n」을 붙인다 |
| 4 | 오늘 할 일 solver 추천 (`strategy.cornerScoreIfPlaced`·`cornerNameForPiece`) | 「이미 만든 명당」을 **도감(`codex.corners`, 완공 뒤 등록)**으로 판단해, 다 모아 놓고 공사만 남은 꽃길의 조각을 또 권했다 | `cornerIdsDoneIncludingWork`로 바꾼다 |
| 5 | 짓기 고스트 배지 (`cornerIfPlaced`) | 완성 명당만 뺐다 → 조각을 다 모은 명당에 대고 「이걸 놓으면 꽃길 완성」을 또 띄웠다 | 완성 + **공사만 남은 것**(`pendingCorners`)을 함께 뺀다 |
| 6 | 배치 점수 명당 성분 (`ui/layoutScore.cornerPart`) | 완공 기준이라 짓는 중엔 0점 | 안내라 `cornersDoneIncludingWork` |
| 7 | 업그레이드 트리 해금 조건 (`tree.stepNeedText`) | 「명당 2개면 열려요」가 짓는 중에도 그대로 | 게이트는 완공 기준 유지 + 「(짓는 중 n)」 |
| 8 | 등급 창 | 명당 줄이 0/1로 멈춘 것처럼 보임 | 숫자 옆에 「· 짓는 중 1」 |
| 9 | 공사 중 미리 알림 | 「공사가 끝나면 꽃길 완성」 — 언제 끝나는지가 없었다 | 남은 공사 일수로 「**내일이면 꽃길 완성**」 / 「n일 뒤 …」 |

## 2. 판정 일원화 (규칙)

- **안내**(튜토리얼 단계·글로우·오늘 할 일·할 일 창·진단·짓기 창 명당 탭·배치 점수·추천·고스트 배지)
  → `cornerProgressIncludingWork` / `cornersDoneIncludingWork` / `cornerIdsDoneIncludingWork` (**공사 중 포함**)
- **보상**(목표 `corners(n)`·월간 과제·등급 승급·손님 요청·트리 해금·도감 등록·요금/인기 효과)
  → `completedCorners` / `codex.corners` (**완공 기준**) + 문구에 「짓는 중 n」

`grep -rn "completedCorners\|cornersMade\|codex.corners" src/` 전수 점검 결과, 남은 완공 기준 호출은
`grade.ts`(승급) · `interact.ts`(손님 요청) · `tree.ts`(해금) · `goals.ts`/`monthly.ts`(목표·과제) ·
`ending.ts`/`guidebook.ts`(집계) · `rangeHint.ts`/`CornerTab.cornerServeText`(완공 뒤에만 나오는 **효과** 표시) ·
`CornerCodex`(도감 등록) 뿐이다 — 전부 보상·효과 쪽이라 의도대로다.

## 3. 공사 중 표시

마지막 조각을 놓는 순간:

- **반투명 명당 팻말** — `render/GameView.syncCornerSigns`가 `completedCorners`에 `pendingCorners`를 더해 닻 칸 위에 세운다 (이미 있었다, 회귀 테스트로 묶음)
- **메시지 한 줄** — `discoverCorners`가 「내일이면 꽃길 완성」을 한 번만 띄운다(`state.cornerSoon`으로 중복 방지)
- **짓기 창 명당 탭** — 「조각은 다 모였다 — 내일이면 완성」 · 머리줄 「명당 0/24 · 짓는 중 1」

| 검사 | 결과 |

회귀 테스트(`cornerRepeat.test.ts`)가 묶은 것:

1. 벤치가 공사 중이어도 5단계 `done` → 마지막 조각을 놓은 액션에서 `tutorial.step` 4→5
2. 공사가 끝난 뒤에도 5단계가 다시 차례에 오르지 않는다
3. 조각을 다 모으면 `cornerMissingKind` = null · `cornerCells` = []
4. 정원등 대신 **가로등**을 놓아도 「불빛 하나 더」를 되풀이하지 않는다
5. 반투명 팻말 근거(`pendingCorners`) + 「내일이면 꽃길 완성」 알림이 한 번만
6. 오늘 할 일·할 일 창·진단·짓기 창 명당 탭 어느 줄도 「짓는 중/다 모였다/완성」 없이 「명당 한 곳 더」로 읽히지 않는다

## 6. 안 고친 것

- **승급·목표·월간 과제·손님 요청·트리 해금·도감은 완공 기준 그대로.** 보상이 걸린 줄을 공사 중에 쳐 주면
  철거했다 다시 놓는 것으로 보상을 흔들 수 있다. 대신 전부 「짓는 중 n」이 붙는다.
- **봇(`bot.ts`)의 명당 만들기**는 손대지 않았다. 안쪽 루프가 이미 `missing.length === 0`이면 넘어가고,
  건드리면 `headless` 수치가 움직인다.
- 튜토리얼 5단계 대사의 「가로등」은 그대로 뒀다. 이제 가로등도 정원등도 같은 「불빛」 조각으로 세므로
  대사대로 해도 막히지 않는다.
- 브라우저 손 플레이에서 **짓기 배치 모드 중 「이 막 건너뛰기」 확인 팝업이 튜토리얼 창 뒤에 가려 클릭을 먹는** 현상을
  한 번 봤다(재현 경로: 📖 → 이 막 건너뛰기). 명당과 무관한 창 z-index 문제라 이번 트랙에서는 손대지 않았다.
