개발 서버 `pnpm dev --port 5423 --strictPort`, 375×812, 새 게임에서 튜토리얼 9단계를 손으로 끝낸 뒤(슬롯 1 저장) 1년차는 손으로, 2~3년차는 `src/sim/bot.ts`의 `botDay`를 브라우저 상태에 그대로 돌려(월별 `dismissAlert`·`dismissMonthCard`) 3년 8월까지 진행했다. 각 시스템은 실제 UI(버튼 클릭·캔버스 합성 PointerEvent `__tap`/`__drag`/길게 누르기)로 조작했고, 시간은 `window.__game.advance(ms)`로 당겼다.

## 3. 스펙 논쟁·다른 트랙 영역 (고치지 않음)

1. **회전(↻)**: `ROTATABLE_TYPES = gate·bench·counter`인데 아이소 스프라이트에 `_r0~3` 변형이 없어 회전해도 그림이 안 바뀐다. 카운터석(counter)을 놓을 때 ↻ 버튼이 뜨지만 효과 없음. 정낭은 카드가 경로 카드라 회전 버튼 자체가 없다. → z-polish(스프라이트) 또는 `ROTATABLE_TYPES`를 비우는 결정.
2. **튜토리얼 2단계 대사**: 「바다 보이는 데 놓아 보라. 고스트 배지의 숫자가 전망이여」인데 시작 필지엔 전망 ≥2 칸이 없어 안내 칸은 길 옆 흙칸(전망 0)이고, 판정도 「테이블 1개면 통과」 폴백이다. 대사(`data/dialogue/tutorial.json`, z-tutorial)를 「길 옆 빛나는 칸」으로 맞추거나 전망 칸을 시작 필지에 두는 안.
3. **고스트 배지**가 화면 오른쪽 끝에서 잘린다(월드 좌표 자식이라 뷰포트 클램프 없음). 카메라를 끌면 보이므로 우선순위 낮음. `GameView.syncGhostSite`에서 렌더마다 글로벌 x를 클램프하면 됨.
4. **본관 증축 완공 뒤 문이 아래로 내려와 올렛길이 끊긴다**(y 통합 기록 §6-3와 같음). 증축 확인 문구에 「문이 아래로 내려와요」가 없고 완공 시 자동으로 잇지 않는다 — z-polish 「rooms 자동 연결」 범위라 손대지 않음. QA에선 문 앞(13,12)에 테이블이 있어 「길 끊김 ✕」 경고가 떴다.
5. **셔틀·크루즈**: 봇 3년 8월 시점 셔틀(용천수 샘터 + 투어 버스 열쇠 또는 명소 Lv2 + 홍보 1회)·선착장(★3 + 곶자왈)이 열리지 않아 UI로 못 봄. 올레길은 3년 1월에 열렸지만 겨울엔 빈 자리가 없어 올레 손님이 줄(waiting)로 빠지며 경로 통계가 0으로 남는다(`spawnGuests`가 자리 없으면 경로 없이 줄 세움) — 통계상 「올레길 0명」이 오래 보일 수 있음. 투어 버스 계약 카드는 열쇠 아이템 전제라 미확인.
6. **돌하르방 마을 팝업 ₩6,553,500**: `generated/regions.json`의 `popupCost: 65535`(원표의 uint16 sentinel로 보임) × 100. 다른 지역은 5만~150만. 데이터(`tools/data`) 쪽 결정 필요.
7. **미니 카드 30vh**: 본관 카드는 버튼 2줄 + 자세히가 넘쳐 스크롤이 필요하다(옮기기 버튼이 반쯤 가려짐). 스펙 수치라 그대로 둠.
8. **채용 공고·승급·연수는 확인 팝업 없이 바로 돈/연구를 쓴다**(홍보·투자·철거는 확인 있음). 통일 여부는 스펙 결정.

11. 셔틀 표지 카드가 잠김 상태에서도 「다음 도착 오늘 15시」·계약 버튼(비활성)을 보여 준다.

## 5. QA 방법 메모

- 캔버스 조작: `window.__view.cellToClient(x, y)`로 셀 → 클라이언트 좌표를 얻고 `canvas.dispatchEvent(new PointerEvent('pointerdown', …))` + `document.dispatchEvent(pointerup)`(Pixi 8은 up/move를 document에서 듣는다). 드래그·길게 누르기(400ms)도 같은 방식. 시간은 `__game.advance(ms)`(speed 무시), 봇은 `import('/src/sim/bot.ts').botDay(state, cursor)`를 라이브 상태에 직접.
- HMR: sim 파일을 고치면 `store.ts`가 다시 실행돼 상태가 시작 마당으로 바뀌던 것을 전역(`globalThis.__jejuHotState`)으로 이어 붙였다(`import.meta.hot.data`는 accept 경계가 아닌 모듈엔 남지 않는다). 그래도 가끔 Vite가 전체 새로고침을 하므로 자동 저장(`?game`)이 복구 수단.
- Browser 도구 탭은 병렬 세션과 공유된다 — 다른 트랙이 같은 탭을 자기 포트로 옮겨 가는 일이 있었다. 탭을 새로 만들고 모든 호출에 `tabId`를 명시할 것.
