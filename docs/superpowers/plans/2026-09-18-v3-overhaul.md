# v3 대격변 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 세 트랙을 git worktree에서 병렬로 진행하고 마지막에 통합한다. 스펙: `docs/superpowers/specs/2026-09-18-v3-overhaul.md`.

**Goal:** 맵이 항상 보이고, 탭하면 반응하고, 목표가 항상 보이는 카이로식 화면으로 갈아엎는다. 밭을 없애고 목표 체인으로 성장 동기를 만든다.

**Architecture:** 트랙 A(sim) / B(콘텐츠·창 내용) / C(셸·상호작용)로 파일 소유를 나눈다. A가 `state.goals`·농원 자동 수확·시작 상태를 만들고, C가 셸(상단 바·목표 줄·하단 바·전체 화면 창·대화창·미니 카드·말풍선)을, B가 창 안 내용(메뉴판·짓기·직원)·라벨·대화 데이터를 만든다. 통합 태스크 D가 셋을 합치고 QA한다.
