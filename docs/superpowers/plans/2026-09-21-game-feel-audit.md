# game-feel 감사 — 「카이로소프트 같은 컨텐츠가 충분히 제공되고 도파민이 제공되는가」 (브랜치 `audit`)

질문(그대로): "게임성 제대로 검증. 카이로소프트 같은 컨텐츠가 충분히 제공되고 **도파민이 제공되는지**."

방법: ① `pnpm dopamine <years> <seed> [--player] [--md]`(신규 `scripts/dopamine.ts`)로 봇 3년의 **보상 사건**을 매일 diff로 세고, ② 카이로 기준선과 비교하고, ③ 375×812 개발 서버(`:5477`)에서 새 게임 → 튜토리얼 → 1년차를 손으로/봇으로 돌리며 일기를 쓰고, ④ 컨텐츠 양을 코드에서 실측했다. 그 뒤 P0를 같은 브랜치에서 고치고 다시 쟀다.

**한 문단 결론(솔직하게)**: 보상 사건의 **총량**은 카이로 수준을 넘는다(1년차 월 14~19건, 3년 해금 160+, 시설 154·손님 103+56·콤보 68·목표 108·도전 40). 문제는 **리듬**이다. 수정 전엔 주요 사건의 73%(봇)/64%(플레이어)가 **매월 1~2일에 몰리고**, 달 중반은 거의 매달 **29일 공백**이었으며, 메인 목표 체인은 막힌 목표 하나 뒤에서 **10개가 한꺼번에 터졌다**(2년 11월 1일 목표 10개, 팝업 11개 연속). 결제는 코인 그림만 뜨고 금액이 안 보였다. 이번에 목표 미리 인정(창 2)·빅 이벤트 발동일 분산·해금 매일 판정·보름 응모권·상성 발견 알림·「+₩」 결제 숫자·자금 튀는 연출·3일 무행동 삼춘 힌트를 넣어 월초 몰림을 73%→58%(봇)/64%→50%(플레이어), 최대 공백을 28→**16일**(플레이어 층), 목표가 몰아 터지는 날을 18→25일로 펴고 빅 이벤트 발동일을 1~2일 61/61 → 19/62로 흩었다. 카이로 기준 "공백 ≤ 15일"에 플레이어 층은 턱걸이(16일)지만, **기본 봇(도전을 안 받고 응모권을 안 쓰는 플레이)은 여전히 29일** — 달 중반의 사건은 플레이어가 도전·뽑기를 스스로 챙겨야만 생긴다. 이벤트 발동 분산 폭을 20일로 넓히면 봇 3년 자금 밴드가 seed별로 ₩8,144만~1.04억까지 튀어(KPI가 rng 흐름에 민감) 8일로 줄였다. 컨텐츠는 "있지만 못 만나는" 축이 크다: 3년 동안 손님층 19/103, 명당 0/12, 히든 레시피 0/10, 도전 0/40(봇), 부탁 7/103. 도파민은 **초반 1시간은 카이로급**(보상 상자 9개·목표 5개·해금 6개), **2개월째부터는 카이로에 못 미친다**.

## 1. 측정 도구 — `pnpm dopamine`

`scripts/dopamine.ts`: `createInitialState(seed)` + `botDay`(bot.ts와 같은 루프)로 N년을 돌리며 매일 상태를 diff한다. `state.alerts.push`·`state.fx.push`를 가로채(봇이 같은 틱에 닫아도 잡힌다) 보상 상자(목표·도전·월간·튜토리얼)·빅 이벤트·장면 창을 세고, `lastDraw`/`lastChallenge`/`lastTour`는 setter로 가로챈다. 나머지(해금·랭크·★·이름 있는 손님 첫 등장·특별 손님·부탁·레시피·콤보/세트/명당/재료 콤보 첫 발견·정착 등급·마을제·칭호·명소 Lv·방문객 상품·월 매출 신기록)는 상태 diff.

- 출력: 구간별 사건 수(1일·6일·10분≈3배속 50일·1개월·1년·3년), 종류별 합계, 월별 표, 사건 간 최대 공백과 긴 공백 TOP 8, 매월 1~2일 몰림 비율, 부정 사건(실패 알림·도전 실패·★강등·악평·이벤트 종료).
- `--player`: 봇 위에 얇은 플레이어 층(도전 2슬롯 수락·게시판 이벤트 수락·응모권 있으면 뽑기). 기본 봇은 도전을 **안 받고** 무료 뽑기만 하므로 기본 봇 수치는 **하한**이다.
- 실시간 환산 주의: 1일 = 36초(1배속), 3배속이면 12초/일 → 실시간 10분 ≈ 50일. 단 창·대화가 열리면 시간이 멈추므로 튜토리얼 중 실제 진행은 훨씬 느리다(손 플레이 §3: 25분에 게임 5일).
- 완공·뽑기 꽝·게시판 제안은 "주요"에서 뺐다(플레이어가 시킨 일의 완료·꽝).

## 3. 손 플레이 일기 (375×812, `:5477`, 새 게임 → 튜토리얼 → 1년차)

시간은 실시간(대략). 1장(11단계)까지는 손으로(캔버스 탭·버튼), 2장부터는 `botDay`를 라이브 상태에 얹고 튜토리얼 단계 액션만 직접 넣었다(z-qa와 같은 방법). ⏳ 기다림 · ⛔ 막힘 · ❓ 설명 없는 실패/해금 · 💤 지루함 · 🎁 보상 없이 지나가는 큰 사건.
