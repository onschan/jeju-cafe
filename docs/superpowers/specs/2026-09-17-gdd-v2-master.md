# 제주 카페 이야기 — 마스터 GDD v2 (제작 지시서 채택 + 현재 구현과의 정합)

작성일: 2026-09-17. 사용자가 제공한 「제주 카페 이야기」 제작 프롬프트(온천골 이야기 2 시스템의 한국화)를 **최상위 설계**로 채택한다. 기존 스펙(`2026-09-17-jeju-cafe-design.md`, `phase2b-kairo-loop.md`, `game-data-tables.md`)은 이 문서 기준으로 조정하며, 충돌 시 이 문서가 우선한다. 지시서의 "산출물 6종" 중 우리 환경에 맞게 바꾼 것(엔진: Godot/Unity 대신 기존 TS+Pixi 웹 스택 유지 — §8)만 명시적으로 표시한다.

## 0. 유지하는 것 (이미 구현·결정)
- 웹 스택(TypeScript, PixiJS 8, React): 순수 결정적 sim + 고정 스텝 + 액션 로그(리플레이·서버 재계산), 모바일 세로 우선. 지시서의 Godot/Unity 요구는 **웹 배포·바로 플레이·기존 자산** 이유로 대체(§8).
- 아이소메트릭 뷰(전환 완료), 32px 타일, 카이로 톤 파츠 캐릭터, Galmuri 폰트, 8비트 사운드, 데이터 설계서 → JSON 도구.
- 시간: 하루 6~24시(AM/PM), 1시간 2초, 한 달 30일. 지시서의 "1개월 = 4주"는 **주 단위 이벤트(주말 팝업·주간 결산)**로 얹는다.
- 첫날부터 판매(구매 재료), 밭 재료 메뉴, 직원이 있어야 열리는 메뉴, 손님 좌석 점유, 홍보 활동·기력, 대사 말풍선.

## 2. 시설 체계
### 2.1 카테고리와 티어
| 카테고리 | 소형(1×1, 40~150만) | 중형(2×1, 150~800만) | 대형(2×2~3×2, 800만~3,000만) |
|---|---|---|---|
| 쉼 | 테라스 좌석, 툇마루, 해먹, 돌담 아래 평상 | 오름 뷰 벤치, 온실 좌석, 소파석 | 루프탑, 비닐하우스 카페룸, 감귤 온실 카페홀 |
| 편의 | 화장실, 포토존, 유모차 보관소, 자전거 거치대 | 주차장(렌터카 필수), 직원 휴게실, 창고, 와이파이 존 | 반려견 놀이터, 대형 주차장 |
| 먹거리 | 핸드드립 바, 한라봉 에이드 스탠드, 오메기떡 매대, 우도 땅콩 아이스크림 | 감귤 타르트 베이커리, 고기국수 분식점, 보말칼국수집 | 흑돼지 구이 식당, 해녀 물회집, 제주 맥주 펍(음료 카테고리 "맥주"는 무알코올 표기 없이 어른 손님 전용 — 초등 사용자 고려해 "제주 보리 음료 펍"으로 명명) |
| 즐길거리 | 소품숍, 보드게임 룸, 스냅사진관 | 도자기 공방, 감귤청 클래스, 북카페 서가, 제주 굿즈 편집숍, 노래방 | 감귤 따기 체험장, 승마 체험, 전동 스쿠터 대여 |
| 농사 | 밭, 감귤나무, 벌통, 닭장 | 녹차 관목 밭, 한라봉 하우스 | 감귤 선과장 |
| 경관 | 유채(봄+12) 수국(여름+9) 억새(가을+9) 동백(겨울+11) 야자수(+5) 삼나무(+8) 현무암 돌담(+4) 돌하르방(+3, 주변 소폭↑) 물허벅(+3) | 연못(+12, 여름+18) | 천년 팽나무(+30, 100주년 보상) |
총 60종 이상 — 상세 표는 `game-data-tables.md` v2 §1(재작성)로.
### 2.2 규칙 (조건 → 결과)
- 동종 시설 n개째 건설 → 건설비 × (1 + 0.1·(n−1)).
- 건설 시작 → 일꾼 삼춘 1명 점유, 소형 1일·중형 3일·대형 7일 후 완공 팡파르("○○ 완공!" 장면 창). 일꾼 초기 2, 마일리지 상점 30→81→138으로 추가.
- 유지비 = 건설비 × 1.5% / 월(대형 10~20만), 매일 1/30 차감 + 하단 메시지.
- 경관 상한 30, 인기 상한 40, 씨앗 아이템도 상한 동일.
### 2.3 해금 조건 스키마
`unlock: { type: 'start' } | { type: 'rank', n } | { type: 'segment', id, popularity: 30|40|60 } | { type: 'star', n } | { type: 'quest', id } | { type: 'spot', id, level } | { type: 'date', year, month } | { type: 'count', objectId, n }`

## 5. 직원
- 스탯 4: **체력 / 힘 / 기술 / 미소**(초기치·상한·최대 레벨·급여). 역할 배치는 유지(바리스타=기술, 요리=기술, 홀=미소, 밭·운반=힘, 안내=미소).
- 채용 5단계: 동네 알바 구인 50만 → 알바천국 공고 500만 → 제주 청년 일자리센터 800만 → 인턴 모집 2,000만(노루 감귤밭 침입 해결 이벤트) → 대학 취업설명회 5,000만(까마귀떼 퇴치). 후보 3~5명 랜덤.
- 직원 풀 20명+(제주 토박이 바리스타, 육지에서 온 파티시에, 은퇴한 해녀 …) + 특수 직원 1(제주 조랑말 인형 획득으로 해금).
- 유니폼(응모권 특별상 5단계): 하와이안 셔츠 → 갈옷 → 해녀복 → 제주 방언 티셔츠 → 산타복. 파츠 시스템의 `top`/`acc`로 표현.
- 급여 40만~220만/월(온천골 400~2,200G).

## 6. 아이템·상점
- **농협 마일리지 상점**(메달): 일꾼 삼춘 고용, 돌담 철거 곡괭이, 응모권, 감귤 씨앗(인기 씨앗)·한라봉 씨앗(가격 씨앗), 5개 묶음팩.
- **응모권 상점**: 유니폼, 경관 씨앗, 인기 열매. 응모권 추첨(룰렛 대체, 인형뽑기 연출).
- **강화 아이템 20종**: 제주 소금, 원두 샘플, 감귤 청, 소라 장식, 갈옷 방석, 오름 사진 포스터, 만화책, LP판, 돌하르방 미니어처, 운동화, 안경, 족자(제주 민화), TV, 도자기 항아리, 금박, 제주 차 세트, 꿀, 꽃밭 포스터, 초롱, 해초 비료 — 시설별 "잘 맞는 시설" 매트릭스(0~3).

| 전국 카페 투어 | ★3 | 종합 | 500만 + 연구 5,000 |
| 블루리본 서베이 | ★4 | 종합 최상 | 1,000만 + 연구 10,000 |
연구 포인트 보상 100 → 10,000 지수 증가. 연 2회(3월·9월) 발표 + 월간 1종.

## 8. 계절·이벤트·엔드게임
- 봄 유채·벚꽃 / 여름 수국·태풍(시설 일시 파손, 유지비↑) / 가을 억새·감귤 수확 / 겨울 동백·**감귤 택배 시즌**(부수입 — 첫 1년 "돈 부족 → 감귤 택배로 버티기 → 첫 흑자" 커브의 핵심).
- 랜덤: 태풍 경보, 비행기 결항(손님 급감), 렌터카 대란(주차장 없으면 이탈), 노루·까치 감귤 습격, 해녀 삼춘 물질 선물, 마을 반상회 요청, 귀농 지원금 심사, 인스타 바이럴(폭증+웨이팅), 방송 촬영 요청, 100주년 감귤축제.
- 15년 종료 → 최종 점수 + 계속하기 + 빠른 모드. 100주년(연장) → 천년 팽나무.

## 9. 기술 스택 (지시서 산출물 3에 대한 답)
Godot/Unity 대신 **TypeScript + PixiJS 8 + React 19** 유지. 이유: (1) 이미 아이소 렌더·sim·에셋 파이프라인이 동작, (2) 웹 배포로 링크 하나로 바로 플레이(모바일 우선), (3) 순수 결정적 sim이 온라인 랭킹 서버 재계산에 그대로 쓰임, (4) Switch/Steam은 Capacitor/Tauri 래핑으로 후속 대응 가능. 아키텍처: 타일맵 배치(`grid.ts`), 인접 콤보 판정(체비쇼프 2칸, `compat.ts`), 손님 AI(입장→시설 순회→만족→소비→퇴장, `guests.ts` 확장: 시설 순회 단계 추가), 시간(`clock.ts`), 세이브/로드(`save.ts`).
