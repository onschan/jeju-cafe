## 3. 손님 유입 경로 시스템 제안 (트랙 H)

### 3.1 현재 구조

- 맵 30×24(3×3 필지, 각 10×8). 시작 필지는 정중앙 (x 10~19, y 8~15). 마을 길 `VILLAGE_ROAD_Y = 15`가 맵 가로 전체(x 0~29)로 이어진다.
- 정류장 `busstop` 1×1이 (10,15)에 고정, 정낭 `gate` (14,14), 본관 `warehouse` 3×2 (13,9), 문 (13,10) → 문 앞 (13,11).
- `spawnGuests()`는 **정류장 1곳**에서만 스폰 → `reachMap` BFS로 가장 가까운 빈 좌석. 투어 버스는 11시, 4~6명, `isBusDay`.
- 상한: 동시 60명, 하루 2~120명.

HSS2에는 "정류장"이 없고 접수처(reception)가 길(stone floor)로 마을 길에 이어지면 손님이 온다. 관광지·투어 버스는 **마을 전체 방문객 수**를 올려 손님 풀을 키운다(W1 28~31/37). 제주판은 이를 **경로 5종**으로 쪼갠다.
