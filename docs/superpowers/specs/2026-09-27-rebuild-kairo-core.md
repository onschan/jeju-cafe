## 사림 (`src/game`)

- **월드**: 3×3 필지(12×10), 가운데가 내 땅. 남쪽 변이 마을 길, 정류장 하나. 칸 = 잔디 | 길 | 바닥(wood·tile·stone) | 올렛길.
- **시설** 세 갈래: **환경**(나무·바위·꽃 — 잔디 위, 경치를 낸다) · **시설**(자리 — 바닥 위, 손님이 앉아 메뉴를 산다) · **가게**(바닥 위, 손님이 이용료를 낸다). 장식(등불·화분)은 어디든.
- **시설 값** = 기본 인기 + 보너스(상성 짝 수 × 4) + 경치(반경 2 환경 합, 상한 20). 요금 = 기본 요금 + 상성 짝 × 200원.
- **손님**: 손님층 7(대학생·주부·회사원·관광객·커플·가족·삼춘) — 지갑·기대치·좋아하는 시설 태그. 하루 손님 수 = 3 + 시설 인기 합/15 + 명성/25 (자리×6 상한). 정류장에서 걸어 들어와 **가장 마음에 드는 빈 시설**을 골라 쓴다 → 돈 → 영수증. 시설 값이 기대치 이상이면 happy(명성 +1, 연구 +2) 아니면 meh(연구 +1).
- **명성(fame)**: happy로 오르고 angry로 내린다. 손님 수·손님층 해금·평가 점수의 뿌리.
- **연구**: 포인트로 카탈로그·메뉴를 연다(연구 창).
- **직원**: 후보 3명(매달 새로), 서비스 1~5·월급. 서비스 합이 손님 회전과 happy 확률을 올린다. 최대 6.
- **투자**: 광고 캠페인(명성 +30)·정류장 증편(하루 손님 +3)·꽃밭 개발(경치 +2 전역)·올레길 정비(관광객 ×1.5) — 각 1회, NEW 배지.
- **평가**: 매년 12월 말 「제주 카페 랭킹」 — 점수 = 명성 + 시설 인기 합. 경쟁 카페 5곳은 해마다 자란다. 순위별 상금.
- **목표**: 코드에 적힌 12개 짧은 사다리(자리 3 → 손님 10 → 인기 20 → …). 한 줄로 보여 준다.
- **시계**: 1시간 = 1,500ms(1×), 하루 6~24시, 30일 = 한 달, 12달 = 1년. 계절 4.
- **적자**: 빨간 숫자. 게임 오버 없음. 잔고가 −200만 아래면 삼춘 대출(300만, 이자 없음, 연 1회).
