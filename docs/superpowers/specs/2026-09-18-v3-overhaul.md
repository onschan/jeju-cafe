# v3 대격변 — 조작감·화면·목표·컨텐츠 전면 개편

> 사용자 피드백(2026-09-18): "조작감이랑 컨텐츠가 카이로소프트류에 비해 현저히 부족. 상호작용은 요소를 **클릭했을 때** 일어나는 상호작용. 화면을 너무 많이 가림. 할망 잔소리 배너 없애고 튜토리얼·퀘스트는 모달로. 밭 필요 없음(9~11월, 3년 뒤 감귤). 메뉴 가독성 나쁨. 성장 욕구가 안 생김. 기존 틀에서 수정하지 말고 대격변."

이 문서는 기존 스펙(2B, GDD v2)을 **덮어쓰는** 결정만 적는다. 적지 않은 것은 그대로다.

---

## 0. 원칙

1. **맵이 주인공.** 기본 상태에서 화면을 가리는 UI는 상단 1줄 + 하단 1줄뿐. 나머지는 눌렀을 때만 뜨고, 닫으면 사라진다.
2. **누르면 반응한다.** 맵의 모든 것(손님·직원·시설·바위·빈 땅·필지·정류장)은 탭하면 **즉시** 말풍선/카드가 뜬다. 정보를 찾으러 탭을 뒤지지 않는다.
3. **3분마다 새로운 것.** 초반 1시간 동안 목표 달성·해금·손님 사연·랭크업 중 하나가 게임 시간 2~3일마다 온다.
4. **말은 다 한국어 이름.** UI 어디에도 `q_local_uncle`, `americano` 같은 id가 노출되지 않는다.
5. **밭은 없다.** 재료는 시설·거래처·손님 보상으로 온다.

## 1. 화면 셸 (UI Shell)

### 1.1 기본 화면
```
┌──────────────────────────────┐
│ 1년 3월 1일  ☀  ₩5,000,000  ★1 │  ← 상단 바 28px. 탭하면 "경영 현황" 창
│ ▶ 목표: 손님 10명 맞이  7/10 ▶ │  ← 목표 줄 24px. 탭하면 목표 창. 완료되면 반짝임
│                              │
│         (맵 전체)             │
│                              │
│ [짓기] [카페] [사람] [장부]  ⏸▶▶▶│  ← 하단 바 48px: 아이콘+한 글자 라벨 4개 + 속도
└──────────────────────────────┘
```
- 할망 배너 **삭제**. `TutorialOverlay` 삭제.
- 하단 바 4버튼: **짓기**(시설/장식/길·담/철거/이동), **카페**(메뉴판·재료 창고·연구 개발·홍보), **사람**(직원·손님 목록·도감·부탁), **장부**(투자/필지·상점(마일리지·응모권)·랭킹·지역/팝업·저장/설정). 속도 버튼은 하단 오른쪽 ⏸ ▶ ▶▶ ▶▶▶.
- 모든 창은 **전체 화면 창**(카이로식): 상단 제목 + 오른쪽 위 `✕`, 내용 스크롤. 창이 열리면 게임은 **일시정지**(카이로 동일). 창 안에서 하위 탭은 상단 가로 탭 바.
- 짓기만 예외: 시설을 고르면 창이 닫히고 맵에 고스트 + 하단에 `회전 · 확정 · 취소` 3버튼(가로 1줄 48px). 게임은 배치 중 일시정지.

### 1.2 탭 상호작용 (맵 위)
탭하면 맵 위에 **말풍선**(Pixi, 1.5초) + 화면 하단에 **미니 카드**(높이 ≤ 30%, 맵 보임, 바깥 탭하면 닫힘).

| 대상 | 말풍선 | 미니 카드 내용 | 버튼 |
|---|---|---|---|
| 손님 | 현재 기분 대사("감귤주스 맛있다!", "자리가 없네…", "비싸다") | 초상·이름/손님층·예산·지금 뭐 하는 중·만족 게이지·좋아하는 것 2개 | `자세히`(기존 GuestPopup), 부탁 있으면 `부탁 듣기` |
| 직원 | 상태 대사("힘이 넘쳐요", "쉬고 싶어요…") | 초상·이름·직종·4스탯 바·에너지·급여 | `승급`, `쉬게 하기/일 시키기`, `자세히` |
| 시설 | 없음 | 아이콘·이름·인기/경관/요금·주변 시너지(콤보) 요약 | `이동`, `회전`, `철거`, `자세히` |
| 바위 | "돌이 크다…" | 치우기 비용·기간 | `치우기` |
| 빈 땅(소유) | 없음 | "여기에 무엇을 지을까?" | `짓기`(짓기 창 열림, 확정 시 이 칸 원점) |
| 미소유 필지 | 없음 | 필지 이름·가격·랜드마크 미리보기 | `사기` |
| 정류장·정낭 | "다음 버스 12시" | 오늘 온 손님 수·다음 버스 | — |
| 본관 카운터 | 없음 | 카페 요약 | `카페 창` |

길게 누르기 → 들어 올려 이동(기존 유지). 드래그 = 카메라(기존).

### 1.3 대화 모달 (튜토리얼·사건·부탁)
카이로식 **대화창**: 화면 하단 1/3, 왼쪽 초상 64×64, 오른쪽 이름 + 2줄 대사, 탭하면 다음. 마지막엔 버튼(`알겠다` / 선택지). 게임 일시정지. 컴포넌트 `Dialogue.tsx`, 호출 `showDialogue({ speaker, lines[], choices? })`.
- 튜토리얼 12단계 → **6단계 대화**로 압축: ①환영+메뉴판 ②테이블+길 ③첫 손님 ④직원 ⑤목표 줄 안내 ⑥끝("이제 알아서"). 각 단계는 조건 충족 시 다음 대화가 **한 번** 뜬다. 진행 중 배너 없음. 현재 할 일은 **목표 줄**이 대신 보여준다.
- 손님 부탁(퀘스트) 수락/완료, 랭크업, 라이벌 등장, 계절 사건 등 전부 이 대화창.

## 2. 목표 시스템 (성장 욕구)

`state.goals: { index: number; progress: number; claimed: string[] }` + `src/data/goals.json`(60개, 순차 체인). 목표 줄에 항상 **현재 목표 1개**와 진행도가 보인다. 달성 시 → 대화창(할망/삼춘 축하 1줄) + 보상 즉시 지급 + 다음 목표.

목표 종류(condition): `guests(n)`, `menuSold(menu,n)`, `money(n)`, `staff(n)`, `facilities(cat,n)`, `satisfied(n)`, `parcels(n)`, `rank(n)`, `stars(n)`, `regular(n)`, `research(n)`, `namedGuest(n)`, `custom(id)`.
보상(reward): `money`, `unlockFacility(id)`, `unlockMenu(id)`, `tickets`, `mileage`, `staffSlot`, `research`, `builder`.

초반 20개 예시(3월~6월에 다 끝나도록):
1 아메리카노 메뉴에 올리기 → ₩30만 · 2 테이블 2개 놓기 → 파라솔 테이블 해금 · 3 손님 5명 맞이 → ₩50만 · 4 직원 1명 채용 → 응모권 1 · 5 손님 20명 → 감귤주스 해금 · 6 감귤주스 10잔 → 화분 장식 해금 · 7 만족 손님 10명 → 연구 10 · 8 홍보 1회 → ₩30만 · 9 손님 50명 → 돌담 해금 · 10 시설 5개 → 건축가 +1 · 11 자금 700만 → 필지 할인권 · 12 필지 1개 구매 → 바위 치우기 해금 · 13 바위 3개 치우기 → 정원 해금 · 14 손님 100명 → ★2 심사 · 15 직원 2명 → 승급 해금 · 16 메뉴 5개 → 연구 개발 해금 · 17 레시피 1개 개발 → ₩100만 · 18 단골 1명 → 응모권 3 · 19 랭크 8위 → 팝업 스토어 해금 · 20 손님 300명 → 이름 있는 손님 등장…

이후 40개는 1년차 말~5년차 (★3~5, 필지 9개, 100주년 준비 등). **연구 해금 트리(UNLOCKS 12)는 목표 보상으로 흡수**하고 연구 포인트는 레시피 개발·승급 전용으로 남긴다.

**해금 리듬**: 시작 시 시설 8종·메뉴 3종만. 목표·랭크·손님 부탁이 나머지를 연다. 시설 109종이 5년에 걸쳐 열린다.

### 2.1 월말 결산 카드 개편
수입·비용 표 + **이달의 하이라이트 3줄**(최다 판매 메뉴, 최고 만족 손님, 새로 열린 것) + **다음 달 팁 1줄**(목표 기반). 카드에 ★ 게이지 변화.

## 3. 밭 폐지 → 재료 공급 개편

- 시설 `field`(밭)·작물 심기·수확·계절·`crops.json`·직원 직종 `field` **삭제**. 저장 v15에서 기존 밭은 철거·환불.
- **감귤나무·당근밭·녹차밭**은 "농원" 카테고리의 **경관 시설**로 남고, 놓으면 **매월 1일** 자동으로 재료 n개가 창고에 들어온다(계절 없음, 첫 달부터). 감귤나무: 감귤 6/월·경관 +2, 당근밭: 당근 8/월, 녹차밭: 녹차 4/월(★2 해금). 카드에 "이달 수확 예정: 감귤 6"이 보인다.
- 나머지 재료는 **거래처**: 카페 창 → 재료 탭에서 재료별 `자동 주문 ON/OFF`(월 단위 계약, 월말 비용). 기본은 필요한 만큼 자동 구매(현재 bought 로직 유지) — 즉 플레이어가 아무것도 안 해도 메뉴는 나간다. 농원 시설이 있으면 그만큼 구매비가 준다(카드에 절감액 표시).
- 튜토리얼·목표·대사에서 밭·심기·9~11월 언급 전부 제거.

## 4. 가독성 (메뉴판·짓기·직원)

### 4.1 메뉴판 창
한 줄 = `[아이콘] 이름(16px 굵게)   ₩4,500   ★★★☆☆   [올리기/내리기]`, 아래 작은 줄: "감귤 1 · 우유 1 · 바리스타 필요" 처럼 **한글 재료명**. 잠긴 메뉴는 "🔒 손님 50명 맞이하면 열려요"(목표 이름). 상단에 "메뉴 슬롯 3/6".
### 4.2 짓기 창
카테고리 탭(쉼·편의·먹거리·즐길거리·농원·경관·길·담). 격자 2열 카드: 아이소 스프라이트 + 이름 + 가격 + 인기/경관 아이콘 숫자. 탭 → 아래 설명 2줄 + `짓기`. 잠긴 것은 반투명 + "손님 100명" 조건 한글.
### 4.3 직원 창
카드 1열: 초상·이름·직종·4스탯 바(라벨 체력/힘/기술/미소)·급여·에너지. 채용 후보도 같은 카드. 승급 버튼에 비용.
### 4.4 공통
- 모든 id → 이름 변환 헬퍼 `label(kind, id)` (`src/data/labels.ts`). 테스트: UI 텍스트에 `/^[a-z_]+$/` 형태 토큰이 없다.
- 폰트 14px 이상, 라벨은 갈색 프레임 안 흰 배경. 버튼 최소 44px 높이.

## 5. 초반 컨텐츠 밀도

- 새 게임 시작 상태: 본관(카운터·주방) + 테이블 2 + 파라솔 1 + 정낭까지 올렛길 연결 + 메뉴 3종(아메리카노·카페라떼·감귤주스) 이미 올라가 있음 + 직원 후보 2명 대기. 첫 손님은 게임 1시간(2초) 안에 온다.
- 손님은 자리에 앉으면 **말풍선으로 주문 메뉴 아이콘**, 나갈 때 **기분 아이콘**. 가끔(20%) 대사 말풍선.
- 직원은 일할 때 `!` 말풍선, 지칠 때 `zzz`.
- 하루 손님 수: 시작 8~12명(테이블 2 기준). 카이로처럼 화면에 항상 3~6명이 움직인다.
- 1년차에 사건 12개(월 1개): 관광 시즌·태풍·감귤 축제·라이벌 예고·삼춘 부탁 등 → 대화창.

## 7. 완료 기준

1. 기본 화면에서 맵이 화면의 88% 이상 보인다(상단 52px + 하단 48px만).
2. 손님·직원·시설·바위·빈 땅·필지를 탭하면 0.1초 안에 카드가 뜬다.
3. 새 게임 시작 후 게임 시간 3일 안에 목표 2개가 달성된다. 1년차 안에 목표 20개.
4. 어떤 화면에도 영문 id가 보이지 않는다(테스트).
5. 밭·심기·계절 제한이 없다. 감귤나무를 놓으면 다음 달 1일 감귤이 들어온다.
6. 튜토리얼은 대화창 6단계이고 배너가 없다.
7. 353개 기존 테스트 중 밭 관련을 제외한 전부 + 신규 테스트 통과, `pnpm build` 성공.
