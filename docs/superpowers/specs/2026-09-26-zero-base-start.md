# 제로베이스 시작 배치 — 실내가 있는 카페, 넓어진 마당 (2026-09-26)

사용자 판정: 「폐건물 기본 실내건물 업데이트 · 정류장 맨 앞 추천 금지 · 정낭 없애고 · 실내 늘릴 수 있고 · 기본 타일 더 늘리고 · 초기 배치를 제로베이스로 두고 다시 게임성 구축」

## 결정

> **본관은 지붕 없는 진짜 카페(4×3, 타일 바닥·카운터·창)다. 안에도 자리를 놓고, 증축하면 실내가 넓어진다(4×3 → 5×3 → 6×4).
> 마당은 12×10(120칸)이고 시작 배치는 본관·올렛길·정류장뿐이다. 정낭은 없다.**

카이로 방향(2026-09-26-direction.md)은 그대로다 — 손으로 하는 건 배치뿐. 「실내」는 바닥 재질일 뿐 건물이 아니고(영상 §1-5 ①),
안이든 밖이든 자리는 같은 규칙(fee.ts 배수 → 등급 A~D)으로 값이 매겨진다. 안 자리는 그늘 2(조용함 손님이 찾는다)·바람 없음, 창 너머 전망은 그대로 본다.

## 시작 배치 (필지 상대, 12×10, ly 9 = 마을 길)

```
본관 4×3  (4..7, 1..3)   문 (4,3)  문 앞 (4,4)
올렛길    (4,4)…(4,8) → 마을 길 (4,9)
정류장    (0,9)
그 밖엔 아무것도 없다 — 첫 테이블은 튜토리얼이 본관 안 (5,2)에 놓게 한다.
```

## 실내 규칙 (grid.ts · path.ts · rooms.ts)

- 본관 바닥 칸(roomId) 중 **뒷벽 줄(y = room.y, x > room.x)은 카운터·주방**(고정, 못 놓고 못 걷는다). 문 칸은 비워 둔다.
- 안에 놓을 수 있는 것: 1×1 좌석·장식. 나무·담·길·시설·명소는 밖에만.
- 놓을 때마다 문 → 카운터 앞 통로와 모든 실내 좌석의 접근 칸이 남는지 검사(indoorRouteCheck).
- 걷기: 가구 없는 바닥은 걷는 칸. 방 경계는 문 칸으로만 넘는다(canStep). 공사 중(build)이면 안 들어간다.
- 증축: Lv2 ₩300만 · Lv3 ₩800만, 5일 공사(그동안 실내 자리는 못 쓴다). 발자국은 오른쪽·아래로 커진다 — 새 문 앞을 막은 것은 치우고 올렛길을 자동으로 잇는다.

## 추천 칸

정류장에서 체비쇼프 거리 1 안의 칸은 자리 후보에서 뺀다 — 「정류장 맨 앞」은 손님이 몰리는 길목이지 자리가 아니다.
후보에는 본관 빈 바닥 칸도 들어간다(안팎을 같은 눈금으로 견준다).
