# 코어 설계 원칙 — 카이로류가 재미있는 이유를 우리 게임에 대입

사용자가 정리한 8가지 원칙(2026-09-23)을 우리 게임의 **현재 상태 진단 → 지켜야 할 규칙**으로 옮긴다. 앞으로 모든 패치는 이 표를 통과해야 한다.

| # | 원칙 | 우리 현재 상태(진단) | 지켜야 할 규칙(확정) |
|---|---|---|---|
| 1 | 숫자가 계속 커지는 쾌감 | 3년차부터 목표·직원·★ 정체, 돈만 쌓임(봇 5년 목표 58/60) | **"다음 단계"가 항상 화면에 1개**(오늘 할 일 1줄 + 목표 줄). 성장은 숫자가 아니라 **모습**으로도(간판·건물·손님 밀도). 정체 구간(3~5년차)엔 새 시스템 1개를 반드시 배치 |
| 2 | 짧은 보상 주기 + 긴 목표 | 사건이 월초에 몰리고 달 중반 공백(최대 12일) | **초 단위**: 결제 +₩ 팝·동전·소리 / **분 단위**: 해금·테마 완성·손님 요청 해결 / **10분 단위**: 목표·랭킹·대회 / **시간 단위**: 등급·엔딩. 어느 층도 비면 안 됨(`pnpm dopamine`으로 측정) |
| 3 | 발견의 재미(조합) | 테마 24종이 있으나 "왜 붙이는지"가 약하고 힌트가 적음 | **실험 → 피드백 → 기록** 루프: 고스트에 "이걸 놓으면 ○○ 완성" 예고, 완성 시 팻말·장면, 도감에 기록, 미발견은 힌트 한 줄. 숨은 조합은 전체의 30%만 숨김 |
| 4 | 선택에 의미(정답 빌드 하나 금지) | 좌석만 늘리면 되는 구조 — 트레이드오프 약함 | **제약 3종**: 땅(필지)·건축가 슬롯·직원 정원. 서로 다른 노선(관광객형/동네 단골형/대회 특화형)이 각각 통하게 수치 설계. 한 노선만 최적이면 밸런스 실패로 본다 |
| 5 | 캐릭터 애착 | 칭호·단골은 있으나 사건이 없음 | 직원에게 **짧은 사건**(첫 대박, 연수 복귀, 대회 우승 소감)과 관계 한 줄. 단골은 이름·얼굴 고정 + 재방문 인사 |
| 6 | 한눈에 읽히는 화면(3초 규칙) | 창·지표가 많아 헷갈림 | 화면에서 3초 안에 **잘 되는 것 / 문제 / 다음 할 일**이 보여야 함. 지표는 3개(인기·경관·서비스)로 고정, 나머지는 접힘. **상태는 움직임으로도**(붐비면 줄·바쁜 직원, 한산하면 파리) |
| 7 | 중후반·회차 | 엔딩·이월은 있으나 중반이 빈다 | 중반(3~5년차)에 **대회·경연**을 배치. 엔딩 후 회차 계승(이월 6종) 유지, 도전 모드는 나중 |
| 8 | 차별화 포인트 하나 | "제주 카페"라는 테마는 있으나 메커니즘 차별화 약함 | **차별화 축 = 제주 관광 생태계**: 날씨·계절·관광객 유입 경로(버스·렌터카·올레)와 **경관(바다·오름 전망)** 이 매출을 좌우하는 구조. 이걸 다른 어떤 요소보다 두껍게 |

## 개발 규칙
- 새 기능은 **코어 루프(손님 → 돈 → 배치/업그레이드 → 더 많은 손님)를 굵게 만드는가**로만 판단한다. 아니면 만들지 않는다.
- 추가 1개당 **덜어내기 1개**를 함께 제안한다.
- 모든 패치는 `pnpm dopamine`(보상 층)과 손 플레이 10분 측정(의미 있는 결정 ≥15·기다림 ≤2분)을 통과해야 한다.
