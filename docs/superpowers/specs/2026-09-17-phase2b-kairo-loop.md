# 2B 스펙 — 카이로 루프 완성 (초반 경제·직원·홍보·단골·확률/히든·넓은 맵)

작성일: 2026-09-17. 본 스펙과 2단계 보강(`2026-09-17-phase2-game-feel-assets.md`)을 보강한다. 충돌 시 이 문서가 우선.

## 배경 (1단계 플레이 피드백)
- 당근·감귤밖에 못 심고 수확까지 벽이 높아 초반에 돈을 못 번다 → **첫날부터 파는 일반 카페 메뉴**가 필요
- 직원 고용이 없다 → 공고·랜덤 후보·월급·역할
- 확률·히든 요소가 없다 → 룰렛, 히든 콤보·레시피, 랜덤 이벤트
- 홍보·광고가 없다
- 맵이 좁고 조작이 어색하다 (2단계 보강 §2B 그대로)

카이로소프트 공식 루프([Cafe Master Story 매뉴얼](https://kairosoft.wiki.gg/wiki/Transcript:Manual_(Cafe_Master_Story)), [HSS2 매뉴얼](https://kairosoft.wiki.gg/wiki/Transcript:Manual_(Hot_Springs_Story_2)))를 기준으로 삼는다: **손님 만족 → 단골·연구 포인트 → 시설·메뉴·직원 성장 → 더 많은 손님**. 확률(개발 성공, 뽑기, 랜덤 이벤트)과 히든(콤보·레시피·아이템)이 그 위에 얹힌다.

모든 수치는 `src/data/*.json`에 두고 코드 수정 없이 바꿀 수 있어야 한다. 아래 숫자는 초안이다.

## 1. 초반 경제 — 첫날부터 판다

### 1.1 재료 두 종류
| 종류 | 예 | 얻는 법 | 원가 |
|---|---|---|---|
| **구매 재료** | 원두, 우유, 설탕, 밀가루, 달걀, 버터, 녹찻잎, 유자청, 얼음 | 점방에서 **자동 보충**(판매 시 재료비 차감). 창고 개념 없음 | 메뉴 가격의 30~40% |
| **밭 재료** | 당근, 감귤, 메밀, 유채, 녹차(자가), 한라봉, 땅콩, 고사리 | 재배·채집 → 창고 | 0 (품질 보통/좋음) |

같은 메뉴라도 밭 재료를 쓰면 원가 0 + "우리 밭" 배지 + 품질↑ + 삼춘 호감. 구매 재료만 쓰면 평범한 카페.

### 1.2 시작 메뉴 (구매 재료만으로 가능, 12개)
아메리카노, 카페라떼, 녹차, 유자차, 아이스티, 핫초코 / 토스트, 스콘, 치즈케이크, 계란 샌드위치 / 크루아상, 쿠키.
가격 2,000~5,500. 해금 트리는 밭 메뉴(당근주스·감귤주스·당근케이크·감귤 스콘·메밀 칼국수·한라봉 에이드 …)와 시설·직원 슬롯으로 이어진다. 총 메뉴 40개.

### 1.3 시작 자금·비용
시작 5,000 → **30,000**. 월말에 월급·재료비·광고비 차감. 빚 없음(돈이 없으면 못 짓고 못 뽑을 뿐). 첫 달부터 흑자가 나는 밸런스(헤드리스 봇으로 검증: 1년차 12달 모두 수입 > 0).

### 1.4 시작 월
**3월**(봄). 유채 관광객으로 시작이 활기차고, 첫 태풍(7~9월)까지 준비 기간이 있다. 당근 파종(9월)까지 6달은 구매 재료 카페로 돈을 번다.

## 2. 직원

### 2.1 역할 7종
| 역할 | 하는 일 | 핵심 스탯 |
|---|---|---|
| 바리스타 | 음료 제조 속도·품질 | 감각 |
| 요리사 | 디저트·식사 제조 | 요리 |
| 홀 | 주문·서빙 속도, 손님 만족 | 서비스 |
| 밭 일꾼 | 심기·수확 자동 | 체력 |
| 채취꾼 | 맵 밖 채집(고사리·해산물·야생화) — 하루 1회 랜덤 수확 | 체력·운 |
| 운반 | 점방 구매 대행(재료비 −10%/레벨), 창고↔주방 | 체력 |
| 안내(3년차 해금) | 관광버스·외국인 응대(🗣), 명소 연결 효율 | 인기·언어 |

### 2.2 스탯·스킬
- 스탯 4개: **서비스 / 요리 / 감각 / 체력** (각 1~99). 인기·운·언어는 스킬로 표현.
- 고유 스킬 1개(후보 20종): 커피 장인(음료 품질+), 손이 빠름(속도+), 제주 토박이(삼춘 호감+), 인스타 감성(관광객 만족+), 외국어(🗣), 튼튼함(체력 소모−), 행운(채집·룰렛 +), 절약(재료비−), 연구광(연구 포인트+), 인기인(손님 유입+) …
- 레벨 1~10. 레벨업은 **연구 포인트**로(카이로식). 레벨업 시 스탯 전부 +, 5·10에서 스킬 진화(예: 외국어→통역사).
- 월급 = 스탯 합 × 계수 (초안 30) + 레벨 × 5,000. 월말 차감.

### 2.3 공고·채용
- **공고** 3등급: 동네 전단(₩10,000, 후보 3명, 스탯 10~40), 구인 사이트(₩50,000, 후보 4명, 30~60), 헤드헌터(₩200,000, 후보 5명, 50~80). 후보는 seed 기반 랜덤 생성(이름·얼굴·스탯·스킬·월급).
- 후보는 게시판에 **한 달간** 남아 있고, 원하는 만큼 고용 가능(슬롯 있을 때만).
- **배치 슬롯**: 홀 2·주방 2·밭 1로 시작, 연구 포인트로 확장(각 슬롯 ★ 등급 조건).
- 해고 가능(퇴직금 = 월급 1개월).
- 직원도 격자 위를 걸어다니는 스프라이트(캐릭터 규격 동일). 얼굴은 머리색·피부·상의색 조합으로 랜덤 조립(파츠 방식 — 에셋 비용 절약).

## 3. 홍보·광고
| 수단 | 비용 | 효과 | 지속 |
|---|---|---|---|
| 전단지 | ₩5,000 | 삼춘·가족 유입 +20% | 1개월 |
| SNS 광고 | ₩20,000 | 관광객 유입 +40%, 인기 게이지 → 📷 쪽으로 | 1개월 |
| 지역 라디오 | ₩50,000 | 전 타입 +25%, 동네 게이지 유지 | 2개월 |
| 유튜버 초대 | ₩100,000 | 성공 확률 60%: 유튜버 방문 이벤트 → 시그니처 있으면 유입 +100% 3개월. 실패: 아무 일 없음 | — |
| 명소 팸플릿·투어 제휴·셔틀 | (본 스펙 §3.6) | 명소별 손님 | 영구 |
동시에 2개까지. 홍보는 **손님 수**를, 시설·직원은 **만족**을 올린다는 분리를 지킨다.

## 4. 손님 만족 → 단골 → 부탁
- 손님 타입별 **단골 게이지** 0~100. 😊 +2, 😐 0, 😠 −1. 50↑ "단골": 방문 빈도 ×1.5, 예산 ×1.3. 80↑ "VIP": 부탁을 가져옴.
- 만족 계산: 메뉴 품질 + 좌석 경치 + 서빙 속도(홀 직원) + 콤보 보너스 − 대기 시간. 타입별 가중치(삼춘은 조용함, 관광객은 경치).
- **부탁(퀘스트)** 월 최대 1개: "당근으로 만든 디저트 먹고 싶어요"(메뉴 조건), "친구 6명 데려갈게요 큰 테이블 있나요"(시설 조건), "감귤 3상자 구해줘요"(재료 조건). 성공 시 돈 + 연구 + 단골 게이지 +20 + **가끔 히든 아이템**. 실패 시 없음.

## 5. 확률과 히든

### 5.1 메뉴 개발 (카이로식)
- 베이스(음료/디저트/식사/시그니처) + 재료 2개 + 담당 직원 선택 → 3일 뒤 결과.
- 품질 = 재료 품질 + 직원(감각·요리) + 난수. 성공 확률 70%(기본), 대성공 10%(품질 +1 등급, 가격 +30%), 실패 20%(재료만 소모).
- **히든 레시피**: 특정 조합은 새 베이스를 발견("메밀+녹차 → 제주 말차 라떼"). 도감에 ??? 로 표시. 10개.
- 기존 메뉴는 재료+돈으로 **레벨업**(가격·인기↑).

### 5.2 히든 콤보
인접 조합 12개 중 3개만 공개. 발견 시 팡파르 + 도감. 예: 돌담+감귤나무 = "바람 그늘"(수확 +20%), 폭낭 그늘+평상 = "삼춘 사랑방"(삼춘 만족 +30%), 정낭+돌하르방×2 = "제주 대문"(관광객 사진 이벤트).

### 5.3 룰렛 (초안 — 사용자가 나중에 조정)
- **월말 정산 후 1회 무료**. 추가 회전은 메달 1개.
- 메달: 부탁 성공, 연말 랭킹, 도감 채우기, 희귀 손님 응대에서 획득.
- 칸 8개: 돈(소) 25% · 연구 +5 20% · 재료 한 상자 15% · 메달 10% · 희귀 장식(히든 아이템 풀에서 랜덤) 10% · 삼춘이 다음 달 방문 확정 10% · 광고 1개월 무료 5% · 꽝 5%.
- 룰렛 화면은 카이로식 원판 + 화살표, 결과 팡파르.

### 5.4 랜덤 발굴
- 폐창고 "뒤지기" 버튼: 월 1회, 30% 확률로 옛 물건(장식 오브젝트 15종 풀) 발견. 밭을 새로 갈 때 5% 확률로 동전·도자기 조각(돈/장식).

### 5.5 희귀 손님·이벤트
- 희귀 손님(유튜버·연예인·외국 셰프·도지사): 조건 만족 시 매월 5~10%. 만족시키면 큰 보상, 실패하면 소문(인기 −).
- 랜덤 이벤트 30개(본 스펙 §3.5)는 각각 월 확률 1~5%.

### 5.6 결정성 유지
모든 확률은 `state.rng`(seed PRNG)로. 리플레이·서버 재계산 가능.

## 6. 진행 사다리
- **★ 등급 1~5**(짧은 사다리): 조건 3개씩(예: ★2 = 월 매출 30만·메뉴 10개·직원 3명). 승급마다 슬롯·홍보 수단·명소·공고 등급 해금.
- **정착 등급 7단계**(긴 사다리, 본 스펙 §6.2) 병행.
- 연말 마을제 = 정착 심사 + 전국 카페 랭킹(★·매출·시그니처·도감으로 점수).
