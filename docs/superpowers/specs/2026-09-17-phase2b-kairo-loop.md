## 1. 초반 경제 — 첫날부터 판다 (v1과 동일)
재료 2종(구매/밭), 시작 메뉴 12, 시작 자금 30,000, 시작 3월, 빚 없음. **유지비**: 오브젝트마다 월 유지비(테이블 200, 하우스 2,000 …)를 월말 차감. 헤드리스 봇 1년차 12달 흑자.

## 2. 하루의 시간
- 하루 = 06:00~24:00(18시간). `HOUR_MS = 200`(×1에서 0.2초 = 1시간, 하루 3.6초, 한 달 ≈ 108초; ×3이면 36초). 시계는 AM/PM으로 표시.
- 손님 스폰은 시간대별 분포(아침 삼춘, 낮 관광객, 저녁 한 달 살기·유튜버). 밤 21시 이후는 도대불 랜드마크 있을 때만.
- 렌더: 18시 이후 화면 틴트 점점 어둡게, 등불(가로등·정낭 초롱) 발광 스프라이트.

## 3. 직원 (v1 + HSS2)
- 역할 7종, 스탯 4(서비스·요리·감각·체력), 스킬 1, 레벨 1~10. **레벨업은 스탯을 골라 올림**(연구P, 비용은 현재 값에 비례).
- **기력** 0~100: 일하면 서서히 감소, 밤에 회복. 기력 낮으면 속도·품질↓. 홍보 활동에 기력 소모.
- 공고 3등급 → 랜덤 후보(이름·얼굴 파츠·스탯·스킬·월급) → 고용 확인 팝업 "○○ 씨를 고용합니다 네/아니요".
- 월급 월말 차감, 미지급 2달 퇴사. 배치 슬롯은 연구P·★로 확장.

## 4. 홍보 활동 (HSS2 영업 활동 방식)
- 직원 1명 선택 → 활동 선택 → 즉시 실행, 직원 기력 −N, 비용은 연구P 또는 돈.
| 활동 | 비용 | 효과 |
|---|---|---|
| 전단 돌리기 | 연구 5 | 삼춘·가족 인기 +3 |
| SNS 포스팅 | 연구 10 | 관광객 인기 +5, 📷 게이지 → |
| 전봇대 광고 | 연구 20 | 전 손님층 인기 +3 (1개월) |
| 라디오 출연 | 돈 50,000 | 전 손님층 +5 (2개월) |
| 유튜버 초대 | 돈 100,000 | 60%: 3개월 관광객 ×2 |
| 아르바이트 나가기 | — | 돈 +4,000 (초반 비상금) |
- 손님층 8종 각각 **인기 0~99**(방문 확률)와 **예산**(최대 지불). 홍보·시설·만족으로 인기가 오르고, 만족 실패·소음으로 내림. 타깃 손님층 지정 시 그 층에 효과 ×1.5.

## 5. 손님층·단골·대사
- 손님층 8: 동네 삼춘, 관광객, 가족, 올레꾼, 한 달 살기, 중국 단체, 개별 외국 여행자, 유튜버. 각각 인기·예산·선호(메뉴 카테고리·경치·조용함·속도).
- 단골 게이지(만족 누적) 50↑ 단골, 80↑ VIP → 의뢰.
- **대사 말풍선**: 만족/불만 시 30% 확률로 표정 대신 짧은 대사. 불만 이유별: "자리가 시끄럽네", "너무 오래 기다렸어", "먹고 싶은 게 없네", "경치가 별로야", "비싸다…". 만족: "여기 좋다", "또 올게", "사진 찍어야지". `dialogue.json`에 손님층별 20개씩.

## 6. 게시판 — 의뢰·이벤트·투자
- **의뢰**(VIP·삼춘·명소에서 옴, 월 최대 2): 조건(메뉴/시설/재료/손님층 만족 N명) + 기한 + 보상(돈·연구·메달·히든 아이템). 대사 팝업으로 제시, "도전하기".
- **이벤트**(확률): 노루 습격, 태풍 경보, 방송 촬영, 폐창고 발굴, 유채꽃 축제 — 수락/거절 선택형은 비용·보상 표시.
- **투자**: 마을 사업(버스 노선 개선 200,000 → 정류장 손님 +20%, 마을 축제 후원 → 삼춘 호감) — 장기 효과.

## 7. 오브젝트·랜드마크·필지
- 오브젝트 정보: 인기(만족 기여)·경치·연구P·유지비·계열(좌석/농사/장식/랜드마크)·설명·**아이템 사용**(장식 아이템으로 인기 +).
- **필지 6개 구매**(돈). 필지마다 **구역 보너스**: 해안 도로변 = 관광객 유입 +30%, 좌석 가격 +10%; 오름 자락 = 경치 +2 전체; 용천수 = 밭 품질 +; 곶자왈 = 채집 +. 필지를 사면 맵 밖 배경에 **바다·오름·마을**이 보이기 시작(배경 레이어).
- **랜드마크**(필지당 1): 범위 내 오브젝트 효율 +(폭낭 그늘 → 좌석 만족 +20%, 방사탑 → 태풍 피해 −30%, 도대불 → 야간 영업, 해녀 불턱 → 해산물). 손님이 랜드마크 쪽으로 더 가고(가중치), 그 구역 좌석 가격 +%.
- 콤보 12(히든 9).

## 8. 확률·히든
메뉴 개발(성공 70/대성공 10/실패 20, 히든 레시피 10), 히든 콤보, **룰렛**(월말 1회 + 메달), **메달 상점**(장식·아이템·직원 스카우트권), 폐창고 발굴, 희귀 손님. 전부 seed 난수.

## 9. 랭킹·등급
- ★ 1~5(조건 3개), 정착 등급 7단계.
- 연말 **전국 카페 랭킹**: 채점 4항목(메뉴·경치·접객·제주다움) 각 0~100 → 종합 → 순위·★·보상. 채점 화면은 HSS2처럼 항목별 게이지 애니메이션.

## 10. 튜토리얼·대화
- 첫 플레이: 할망 대사 팝업 12단계(메뉴판 → 테이블 → 손님 → 공고 → 채용 → 밭 → 수확 → 홍보 → 의뢰 → 룰렛 → 필지 → 랭킹). 각 단계는 실제 행동으로 완료, 스킵 가능.
- 확인 팝업: 고용·해고·구매·투자·룰렛 전부 "네/아니요".
- 이벤트·의뢰 대사는 캐릭터 초상 + 텍스트, 카이로식 갈색 프레임 UI.

## 11. 타이틀·세이브
타이틀 화면(로고·배경·시작/최고 점수/사이트), 세이브 슬롯 3 + 자동, 이어하기. 최고 점수 = 연말 랭킹 종합 점수 최고치.

## 12. 뷰 방식 — 결정: 아이소메트릭 전환 (2B-3)
HSS2·Cafe Master Story는 **아이소메트릭(2:1 다이메트릭)**. 현재 우리는 탑다운. 아이소로 바꾸면 격자·sim은 그대로이고 렌더 좌표 변환 + 타일·오브젝트 스프라이트를 아이소로 다시 생성(파츠·프로시저럴이라 도구로 재생성 가능, 캐릭터는 그대로). 카이로 감성에는 아이소가 결정적. 2026-09-17 사용자 결정: 아이소로 전환. 2B-1·2B-2는 탑다운 렌더 위에서 진행하고 2B-3에서 뷰를 바꾼다(sim 무관).
