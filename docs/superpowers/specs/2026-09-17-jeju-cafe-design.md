# 제주 귀농 카페 (가제) — 설계 스펙

작성일: 2026-09-17
상태: 브레인스토밍 완료, 구현 계획 작성 전

## 0. 한 줄 요약

서울 생활을 접고 제주 중산간의 폐창고와 묵은 감귤밭을 물려받아, 밭에서 키운 재료로 카페를 운영하며 15년에 걸쳐 "우리 마을 사람"이 되어 가는 카이로소프트 스타일 경영 시뮬레이션. 모바일 웹 우선.

## 1. 목표와 제약

| 항목 | 결정 |
|---|---|
| 목적 | 취미 + 포트폴리오. 완성이 최우선 |
| 플랫폼 | 모바일 웹 우선(세로, 터치). 데스크톱은 같은 화면을 가운데 배치 |
| 분량 | 한 판(시작→15년 엔딩) 10시간 이상. 엔딩 후 계속 플레이 가능 |
| 깊이 | **배치 퍼즐**(밭·돌담·카페 격자) + **메뉴 해금**(재배→레시피) 두 축. 나머지는 얕게 |
| 시간 진행 | 카이로식 실시간 자동 + 배속(×1/×2/×3) + 일시정지. 방치형 아님 |
| 캐릭터 | 걸어다니는 스프라이트 |
| 해상도 | 32px 타일, 캐릭터 32×48 |
| 확장 | 인접 필지 구매(최대 6필지) |
| 엔딩 | 정착 등급(긴 사다리) + 연말 결산(짧은 목표) + 엔딩 후 계속 성장 |
| 에셋 | 전부 직접 제작. 카이로소프트 느낌의 동일 픽셀아트 톤. 실사·외부 에셋 없음. 개발 중엔 플레이스홀더 |
| 사용자층 | 성인 주 사용층이지만 **초·중학생도 혼자 시작할 수 있어야 함** |
| 온라인 | 1차 범위 아님. 단, 나중에 로그인·랭킹을 붙일 수 있게 구조를 잡음 (§9) |

## 2. 접근성 원칙 (스펙 전체에 적용)

1. **처음 30분엔 규칙 3개만**: 심는다 → 판다 → 짓는다. 나머지는 해금될 때 팝업 한 줄로 배움
2. **숫자 대신 얼굴**: 손님 말풍선(😊/😐/😠), 작물은 시들거나 반짝임. 상세 수치는 탭해야 보임
3. **실패해도 망하지 않음**: 태풍은 손해지 게임오버가 아님. 빚 없음. 돈 부족하면 기다리면 됨
4. **다음 해금이 항상 보임**: HUD 상단에 "다음: 돌담 (연구 2/5)" 상시 표시
5. **읽기 부담 최소**: 팝업 한 개에 한 문장, 초등 어휘. 한자어 대신 쉬운 말("자급률" → "우리 밭 재료"). 제주 방언은 삼춘 대사에 가끔만, 뜻은 그림으로 전달
6. **아이콘이 먼저, 글은 보조**: 메뉴·작물·시설 모두 아이콘 + 짧은 이름. 수치는 ★로 표시
7. **터치 타깃 48px 이상**. 건물 이동·판매는 언제나 무료(되돌리기 가능)
8. **안내자 캐릭터**: 감귤 할망이 첫 1년 동안 다음 할 일을 알려줌. 이후엔 원할 때 탭
9. **술 관련 콘텐츠 없음**: 양조장·막걸리 제외. 음료·디저트·식사만
10. **실패 화면 없음, 축하 화면 많이**: 첫 수확·첫 손님·첫 콤보마다 짧은 팡파르

## 3. 월드와 격자

### 3.1 시간
- 1년 = 12개월. 1개월 = 게임 내 30일, 1일 = 실시간 2초(×1). 1년 ≈ 12분 순수 진행
- 절기(신구간·영등굿 등)는 **이벤트 이름으로만** 등장. UI는 월 표시
- 계절 4개가 타일 팔레트·손님 구성·작물 가능 여부를 바꿈
- 탭이 백그라운드로 가면(`visibilitychange`) 자동 일시정지

### 3.2 격자와 필지
- 시작 필지 10×8칸. 최대 6필지 → 약 30×24칸
- 칸 종류: **흙**(밭 가능), **현무암 바닥**(건물 가능·밭 불가), **길**
- 필지는 인접 구매. 일부는 삼춘 호감도 조건

| # | 필지 | 지형 특성 |
|---|---|---|
| 1 | 중산간 폐창고 (시작) | 평지, 바람 보통 |
| 2 | 오름 자락 | 바람 강함, 풍경 보너스 큼 → 뷰 카페 자리 |
| 3 | 곶자왈 가장자리 | 나무·돌 장애물 많음, 바람 약함, 녹차·고사리 |
| 4 | 밭담 골짜기 | 돌담이 이미 깔림. 삼춘 호감도 조건 |
| 5 | 해안 도로변 | 관광객 유입↑, 소금 바람 작물 −, 소음↑ |
| 6 | 용천수 샘터 | 물 보너스, 물허벅·빨래터. 호감도 최고 등급 조건 |

### 3.3 배치 규칙 — 오브젝트 수치 3개
| 수치 | 의미 |
|---|---|
| `scenery` 풍경 | 주변 칸에 주는 풍경 점수(+/−) |
| `noise` 소음 | 주변 칸에 주는 소음 |
| `wind` 방풍 | 북서풍을 막는 힘 |

수확량·좌석 수는 오브젝트 종류에 내장(밭은 수확, 테이블은 좌석).

- **바람**: 항상 **북서 고정**. 밭 칸의 북서쪽 3칸 안에 `wind` 합이 3 미만이면 수확 −50%. 태풍 달(7~9월 중 랜덤 1회 + 경고 1개월 전)엔 방풍 안 된 작물 소실
- **경치 점수**: 좌석 칸 반경 2칸의 `scenery` 합 − `noise` 합. 손님 만족도와 메뉴 단가 상한을 결정
- **콤보**: 인접 조합 **12개 고정**. 시작 시 3개 공개, 나머지는 도감에 "???"로 표시. 발견 시 팡파르 + 도감 등록

### 3.4 동선
- 손님은 정류장(도로변 고정)에서 출발 → 정낭 → 길 타일 → 빈 좌석까지 A* 경로. 길이 끊기면 못 들어옴(플레이어가 길을 깔아야 함)
- 정낭은 걸친 막대 수(0~3)로 **영업/외출 토글** UI 겸용

### 3.5 제주 요소
**랜드마크** (필지당 1개, 2×2~3×3 대형 오브젝트, 연구·이벤트로 해금):

| 랜드마크 | 효과 |
|---|---|
| 폭낭(팽나무) 그늘 | 반경 3칸 여름 만족도↑, 삼춘들이 모여 앉음(호감도 자동 상승) |
| 돌하르방 한 쌍 | 정낭 양옆 배치 시 사진 이벤트 → 인기↑ |
| 방사탑 | 태풍 피해 −30%, 마을 행사 장소 |
| 동자석·산담 | 조용한 풍경 +. 반경 내 시끄러운 시설 불가 |
| 연자방아 | 메밀 가공 효율↑ |
| 해녀 불턱 (해안 필지) | 해산물 재료 공급, 해녀 삼춘 단골 |
| 오름 전망대 | 격자 밖 오름 배경이 보이는 좌석 = 최고 경치 |
| 도대불(옛 등대) | 밤 영업 해금, 야간 손님 |

**일반 오브젝트 (제주)**: 밭담, 정낭, 물허벅 거치대, 올렛길 타일, 돗통(장식), 억새, 동백나무(겨울), 유채꽃밭(봄 관광객), 귤창고, 감귤 선과장, 그림 메뉴판, 기념품 매대, 큰 테이블, 주차장 등. 총 오브젝트 **40종**.

**절기 이벤트 (고정)**:
- 신구간(1월 말~2월 초): 제주 이사철. 이 달에만 필지 구매 30% 할인(건물 이동은 언제나 무료)
- 영등굿(2~3월): 바람 2배, 끝나면 봄 수확 보너스
- 유채꽃 시즌(3~4월): 관광객 3배, 소음·호감도 위험
- 장마/태풍(7~9월): 방풍 준비 여부로 손익. 태풍 후 삼춘이 돕는 이벤트(호감도 높을 때)
- 감귤 수확철(11~1월): 일손 부족 → 삼춘 품 빌리기 / 손님 체험 수확
- 춘절(1~2월)·국경절(10월): 외국인 단체 급증
- 마을제(12월): 연말 결산 + 정착 등급 심사

**랜덤 이벤트 30개** (예: 까마귀 떼, 노루 당근밭 습격, 방송 촬영 요청, 폐창고 옛 물건 발견, 올레꾼 단체, 외국 유튜버, 첫눈 도로 결빙 등)

### 3.6 제주 명소 지도 (격자 밖)
별도 지도 탭. 실제 명소 **12곳** 고정(성산일출봉, 한라산, 우도, 협재·금능, 섭지코지, 천지연·정방, 만장굴, 주상절리, 용두암, 비자림, 오설록 녹차밭, 동문·올레시장). 각 명소는 관광객 타입·시즌·연결 효과를 가짐.

**연결 3단계** (명소당): 팸플릿 비치(+10%) → 투어 제휴(관광버스 단체) → 셔틀 운행(코스 포함, 소음 관리 난도↑).

명소 이벤트: 성산 새해 일출 새벽 손님, 한라산 첫눈 등산객, 협재 불꽃축제 야간 손님, 올레 스탬프 포인트 지정 등.

## 4. 농사와 메뉴

### 4.1 작물: 시작 2종 → 최종 8종
감귤·당근으로 시작 → 메밀, 유채, 녹차, 한라봉(하우스), 우도 땅콩(우도 연결), 고사리(곶자왈 자생) 순 해금. 해산물은 해녀 불턱 효과로만 획득.

| 작물 | 계절 | 생육 | 특성 |
|---|---|---|---|
| 감귤 | 나무, 11~1월 수확 | 3년 후 첫 수확 | 바람 민감. 게임의 척추 |
| 당근 | 가을 파종 → 겨울 | 2개월 | 바람에 강함, 초반 효자 |
| 메밀 | 봄·가을 2기작 | 1개월 | 꽃이 풍경 +1 |
| 유채 | 가을 → 봄 개화 | 4개월 | 수확보다 꽃 관광객 |
| 녹차 | 영구, 봄 수확 | 2년 | 곶자왈·그늘 |
| 한라봉 | 하우스 | 나무 | 바람 무시, 풍경 −2 |
| 우도 땅콩 | 여름 | 3개월 | 우도 연결 시 |
| 고사리 | 봄 자생 | 채집 | 심지 않음 |

### 4.2 농사 루프
밭 칸 탭 → 작물 선택 → 자동 생육 → 반짝이면 탭해서 수확. 직원(밭 일꾼)이 있으면 자동.
- 품질 **보통/좋음** 2단계: 방풍 되고 풍경 좋으면 "좋음"
- 부패 없음. 창고는 저장량 상한만(귤창고로 확장)

### 4.3 메뉴: 연구 포인트로 해금
- 손님이 😊로 나갈 때마다 연구 포인트 적립 → 해금 트리에서 순서대로 해금(실험·실패 없음)
- 카테고리 4종: 음료 / 디저트 / 식사 / 시그니처. 총 **30개**
- 메뉴판 슬롯 4개 → 8개. 매월 편성이 핵심 결정
- 재료 없으면 메뉴 회색 → 밭을 늘리거나 점방에서 구매(비쌈)
- 배지 **"밭에서 온 카페"**: 판매 메뉴 재료의 60% 이상이 내 밭 → 만족도·단가·호감도 +
- 계절 궁합은 "여름엔 시원한 메뉴 인기" 정도의 단순 보너스

### 4.4 시그니처
랜드마크 1개 + "좋음" 재료 + 해당 메뉴 = 시그니처 등록(최대 3). 연말 랭킹 핵심 점수. 유튜버·개별 외국 여행자가 찾아옴.

## 5. 손님과 직원

### 5.1 손님 타입 (해금 순)
| 해금 | 타입 | 좋아하는 것 |
|---|---|---|
| 시작 | 🧢 동네 삼춘 | 식사, 조용함 |
| 시작 | 📷 관광객 | 음료, 풍경 좋은 자리 |
| 2년차 | 👨‍👩‍👧 가족 | 디저트, 큰 테이블 |
| 명소 연결 | 🥾 올레꾼 | 든든한 식사, 빠른 서빙 |
| 3년차 | 💻 한 달 살기 | 매일 오는 단골, 시그니처 |
| 명소(용두암·성산) | 🇨🇳 중국 관광객 | 단체(3~6명), 기념품·사진, 짧은 체류 |
| 5년차 | 🌏 개별 외국 여행자 | 혼자, 오래 앉음, 시그니처·조용한 자리 |
| 랜드마크 | 🎥 유튜버 | 시그니처, 사진 이벤트 |

손님 행동은 하나: 들어옴 → 앉음 → 메뉴 1개 주문 → 말풍선 → 나감.
😊 = 돈 + 연구 포인트 + 인기. 😠 = 그냥 나감(벌점 없음). 이유는 탭하면 한 줄.

### 5.2 외국인 손님 규칙
- 주문 말풍선이 **"?"**로 뜸. 해결 못 하면 😐로 나감
- 해결 수단(해금 순): 그림 메뉴판(50%) → 외국어 가능 직원 🗣(100%) → 번역기 태블릿(100%)
- 단체는 자리 부족 시 우르르 😠 → 큰 테이블·주차장 동기
- **기념품 매대**: 단체가 감귤 초콜릿·귤 잼 구매 → 수확물의 두 번째 판로
- 특정 국가를 웃음거리로 만드는 연출 금지. "말이 안 통하는 손님 맞이하기"가 규칙의 전부

### 5.3 인기 ↔ 동네 게이지
HUD 게이지 하나: 🧢동네 ↔ 📷인기. 관광객·단체는 인기 쪽, 삼춘 자리·조용한 시설은 동네 쪽.
양 끝은 손해(인기 끝: 삼춘 안 옴 / 동네 끝: 돈 안 벌림). **가운데 근처면 보너스**.

### 5.4 직원
최대 4명, 역할 3개: 밭 일꾼(자동 수확) / 홀(주문 속도) / 주방(조리 속도). 스탯 없이 레벨 1~5만. 마을 게시판에서 3명 중 선택, 얼굴·한 줄 소개·좋아하는 작물·🗣 여부 정도의 개성.

### 5.5 삼춘 6명
감귤 할망(밭 스승·안내자), 해녀 삼춘, 이장님(필지 허가), 돌챙이(돌담 콤보), 점방 삼춘(재료 도매), 옆집 젊은 귀농인(라이벌).
각 ❤ 5칸. 오르는 방법 셋: 😊로 나감 / 절기 이벤트에서 도움 / 수확물 선물. ❤이 찰 때마다 해금 1개(미리 표시).

## 6. 성장과 동기

### 6.1 세 겹의 목표
| 주기 | 목표 | 보상 |
|---|---|---|
| 매 분 | 수확 반짝임 탭, 😊, 연구 포인트 | 손맛 |
| 매 달 | 월말 정산 카드 1장 + 다음 해금 진행 바 | 작은 성취 |
| 매 년 | 마을제: 삼춘들이 점수 발표 → 정착 등급 승급 + 랭킹 | 큰 성취 |

### 6.2 정착 등급 7단계
육지것 → 낯익은 사람 → 옆집 → 동네 사람 → 삼춘 → 우리 마을 사람 → 마을 어른.
승급 조건은 매번 3개, 미리 표시. 승급마다 필지 해금 + 명소 연결 1개 + 컷신.

### 6.3 해금 트리
총 80개, **분기 없는 일직선**. 항상 다음 3개가 보임. 오브젝트 40 · 메뉴 30 · 랜드마크 8 · 기타(손님 타입, 슬롯 확장 등).

### 6.4 수집
콤보 도감 12 · 메뉴 도감 30 · 손님 도감 8 · 삼춘 사연 앨범 6×5.

### 6.5 엔딩과 이후
15년째 마을제에서 등급별 엔딩 컷신(모든 등급에 엔딩 있음). 이후 계속 플레이: 도감·랭킹·마을 어른.
2회차: 시작 필지 지형 선택(해안/오름) → 같은 규칙, 다른 퍼즐.

## 7. 기술 구조

### 7.1 스택
Vite · TypeScript · React 19 · PixiJS 8 · Vitest. 데이터는 JSON. 정적 배포(Vercel/GitHub Pages) + PWA 매니페스트.

### 7.2 레이어 (의존은 아래로만)
```
ui/      React — 메뉴·패널·팝업·HUD
render/  PixiJS — 격자·스프라이트·걷기·말풍선
sim/     순수 TS — 게임 규칙 전부. DOM·Pixi·Node 전용 API 의존 0 (Deno에서도 실행 가능해야 함)
data/    JSON — 작물·메뉴·오브젝트·이벤트·해금·대사
```
- `sim`의 공개 API는 `tick(state, dt): state`와 `apply(state, action): state` 둘. 상태는 직렬화 가능한 순수 객체
- `render`/`ui`는 상태를 읽기만, 입력은 `action`으로 전달. Pixi 씬은 상태 diff로 갱신

### 7.3 sim 모듈
| 모듈 | 책임 |
|---|---|
| `clock` | 일·월·년 진행, 절기 이벤트 트리거 |
| `grid` | 필지·칸·오브젝트, 풍경/소음/방풍 계산, 콤보 감지 |
| `farm` | 생육·수확·창고 |
| `menu` | 슬롯, 재료 소비, 배지 |
| `guests` | 스폰 가중치, A* 경로, 주문·만족·말풍선, 외국인 "?" 규칙 |
| `staff` | 고용·레벨·자동 작업 |
| `village` | 삼춘 호감도, 정착 등급 심사 |
| `map` | 명소 연결 단계 |
| `events` | 고정 + 랜덤 이벤트 큐 |
| `progress` | 연구 포인트, 해금 트리, 도감 |
| `save` | 직렬화, 버전 마이그레이션 |

### 7.4 데이터 표
`crops.json` `menus.json` `objects.json` `landmarks.json` `spots.json` `guests.json` `events.json` `unlocks.json` `villagers.json` `dialogue.json` — 코드 수정 없이 밸런싱.

### 7.5 에셋 규격
| 종류 | 크기 | 프레임 | 경로 |
|---|---|---|---|
| 지형 타일 | 32×32 | 계절 4 | `tiles/{name}_{season}.png` |
| 오브젝트 | 32×32 ~ 96×96 (칸 배수) | 정지 1 (+선택 애니 2) | `objects/{id}.png` |
| 캐릭터 | 32×48 | 4방향 × 걷기 3 | `chars/{id}.png` |
| 말풍선·아이콘 | 16×16 | 1 | `ui/` |
| 명소 배경 | 390×160 | 1 | `spots/{id}.png` |
| BGM | ogg 루프 | 계절 4 + 마을제 + 타이틀 | `audio/bgm/` |
| SFX | 짧은 ogg | 12개 | `audio/sfx/` |

플레이스홀더는 색 사각형 + 이름 텍스트를 코드로 생성. 로더는 실제 파일이 있으면 그것, 없으면 플레이스홀더로 폴백.

### 7.6 성능·모바일
최대 720칸, 손님 30명 → 스프라이트 1천 개 수준. 세로 고정 캔버스, 핀치 줌·드래그. UI는 하단 시트.

### 7.7 테스트
- `sim` 단위 테스트(Vitest): 바람 규칙, 콤보 감지, 경로, 정산, 저장 왕복, 외국인 "?" 규칙
- **헤드리스 시뮬레이터**: 봇이 15년 자동 플레이 → 돈·등급 곡선 CSV → 밸런싱 근거
- 렌더·UI는 수동 확인

### 7.8 구현 순서 (개요)
1. sim 코어(clock·grid·farm·menu·guests) + 헤드리스 테스트
2. Pixi 격자 + 플레이스홀더 + 배치 UI → 1년차 플레이 가능
3. 태풍·돌담·필지·직원·해금 트리 → 3년차
4. 삼춘·명소·랜드마크·외국인·정착 등급 → 15년 엔딩
5. 세이브·도감·컷신·PWA·에셋 교체

## 8. 세이브
자동 저장(월말) + 슬롯 3개. 1차는 localStorage.
- 세이브 포맷에 `version`, `playerId`(로컬 UUID), `createdAt`, `actionLog`(최근 N개) 필드를 처음부터 포함
- 저장 계층은 `SaveStore` 인터페이스(`load/save/list`)로 추상화. 1차 구현은 `LocalSaveStore`

## 9. 온라인 (2차 범위 — 1차에서는 구현하지 않음, 구조만 대비)

### 9.1 원칙
핵심 루프는 오프라인으로 완결. 온라인은 위에 얹는 층. 서버가 죽어도 게임은 돌아감. 로그인 강제 없음.

### 9.2 권장 구성
- **1단계**: Supabase 익명 로그인 + 닉네임 + 카카오톡 **공유 링크**(로그인 불필요)
- **2단계**: 카카오 로그인은 성인 사용자의 기기 이전 용도로 선택 연동. 14세 미만 법정대리인 동의 이슈 때문에 강제하지 않음. 카카오 친구 목록 API는 사용하지 않음(초대 코드로 대체)

### 9.3 랭킹 3종
마을제 점수(시즌 1주 리셋) · 시그니처 ❤(카드에 좋아요) · 마을 어른 도달 순(명예의 전당).

### 9.4 치팅 방지
점수만 보내지 않고 세이브 스냅샷 + 행동 로그를 보내, Edge Function(Deno)에서 **같은 `sim` 코드로 재계산**. 불일치 시 랭킹 제외. → `sim`이 Node/DOM 전용 API를 쓰지 않아야 하는 이유.

### 9.5 테이블(예정)
`profiles` · `seasons` · `scores` · `signatures` · `hall_of_fame`, RLS 적용.

### 9.6 1차에서 지켜야 할 것
- `sim`은 순수 TS, 결정적(같은 seed·같은 액션 → 같은 결과). 난수는 상태에 든 seed 기반 PRNG 사용
- 세이브에 `playerId`·`actionLog`·`version` 포함(§8)
- `SaveStore` 인터페이스로 저장 계층 교체 가능
- 결산 카드는 캔버스로 PNG 생성 가능하게(공유 링크 대비)
